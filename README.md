# Metro: Last Light Redux 1.0.0.3 — меню предметов (прототип)

Заявленная пользователем версия — **1.0.0.3** (не-Steam сборка). Сам номер версии не определяет точный состав исполняемого файла: он не подтверждает совместимость адресов памяти или таблиц для Steam-сборки. Пока адаптер не подключён, меню одинаково работает без игры.

Для Windows написано меню с глобальной клавишей **F1**. Есть категории оружия, боеприпасов и снаряжения, поиск и выбор количества. Повторное F1 или Esc скрывает меню; кнопка «Выход» завершает программу.

> **Важно:** сейчас это интерфейс, а не работающий внутриигровой спавнер. Выдача предметов **не подключена**: кнопка сообщает, что предмет не выдан. Каталог содержит названия, а не подтверждённые ID объектов движка. Изменений памяти игры или сохранений приложение не делает. Без проверенного адаптера нельзя честно обещать выдачу всех предметов для произвольной сборки.

## Запуск на Windows

Нужен Python 3 с Tkinter (обычная установка Python с python.org). Запусти `start-menu.bat` или в PowerShell из папки проекта:

```powershell
py -3 -m metro_spawner
```

При запуске окно показывается сразу. Во время игры F1 открывает/скрывает меню глобально, если горячая клавиша не занята другой программой. В эксклюзивном полноэкранном режиме окно может быть не видно — попробуй оконный или безрамочный режим. Закрытие окна крестиком лишь скрывает его; полностью закрыть можно кнопкой «Выход».

Для настоящей выдачи под проверенную сборку потребуется реализовать `metro_spawner/game_backend.py`: `spawn(item_key, quantity)` должен проверять игру, выдавать предмет и сообщать об ошибках. Не вставляй туда случайные адреса памяти из таблиц для других версий. Для версии игры, когда будет доступ к ПК, есть отдельный **необязательный** скрипт `diagnose-metro.ps1` (только читает сведения о `.exe`; не пересылай сам `.exe`).

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\diagnose-metro.ps1 -GamePath "C:\ПУТЬ\К\ИГРЕ\metro.exe"
```

Скрипт создаст `metro-diagnostic.txt` с версией и хешем исполняемого файла. Перед отправкой убери из отчёта личные сведения в пути к файлу.
