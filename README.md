# MetroCraft Port — Minecraft Forge 1.12.2

Первый этап переноса предоставленного MetroCraft-пака с 1.7.10 на **Minecraft 1.12.2 / Forge 14.23.5.2860 / Java 8**. Это отдельный мод `metroport`, без зависимости от старого Flan's Mod.

## Три вкладки

| Вкладка | Содержимое |
| --- | --- |
| **Оружие** | 16 стволов: АК-74, АКС-74У, Дуплет, ПКМ, Подонок, Превед, Револьвер, РПК, Сайга, СВД, Тихарь, Винтовка, ВССК, ВСВ, Ублюдок, Убойник |
| **Броня** | 36 носимых предметов брони, шлемы, противогаз, ПНВ |
| **Вещи** | 6 видов патронов, 5 модулей, 3 медицинских/ремонтных инструмента, 5 предметов/валют |

Всего **71 предмет**. Названия, исходные иконки, звуки стрельбы/перезарядки и параметры импортируются из приложенного пака. Реестр всех предметов: `src/main/resources/assets/metroport/content.json`; отчёт: `docs/import-report.json`.

## Управление и механики

- **ПКМ** — огонь. Автоматическое оружие стреляет при удержании; полуавтоматическое — при активации ПКМ (с учётом повторной активации использования предмета в Minecraft).
- **R** или **Shift + ПКМ** — перезарядка. Клавиша переназначается в настройках.
- Новое оружие появляется **с пустым магазином**. Положите подходящие патроны в инвентарь и перезарядите. В творческом режиме патроны не требуются.
- Расход боеприпасов, таймеры, урон, износ и перезарядка обрабатываются сервером. Смена оружия отменяет перезарядку без потери патронов. Вместимость и время перезарядки взяты из пака.
- Используется **мгновенная трассировка до 100 блоков** с остановкой на блоках, а не старая система летящих пуль Flan. Дробь суммируется перед нанесением урона; стандартные правила PvP и интервалы неуязвимости Minecraft сохраняются.
- **Аптечка АИ-2:** ПКМ, +8 здоровья, 5 применений; не расходуется при полном здоровье. Между применениями — 1 секунда.
- **Ремкомплект:** держите повреждённое оружие/броню во второй руке, а соответствующий ремкомплект — в основной; ПКМ полностью восстанавливает прочность. Комплект расходуется только при успешном ремонте.
- Броня надевается в обычные слоты. Защита адаптирована к ванильной системе (`round(Defence × 20)` очков, до 16 на предмет), прочность взята из оригинала. ПНВ даёт ночное зрение при ношении; после снятия эффект исчезает в течение 15 секунд.

## Что ещё НЕ перенесено

**Это не полный перенос всех четырёх JAR.**

- Старые объёмные модели оружия и брони: оружие сейчас использует плоскую модель с оригинальной иконкой; надетая броня — стандартную железную геометрию и текстуру. Оригинальные иконки брони сохранены.
- Установка прицелов, глушителей и других модулей: сами предметы доступны, но пока не устанавливаются и не меняют характеристики.
- Радиация, расход фильтров и газовая защита. Противогазы пока работают как обычная броня, что указано в подсказке.
- Специальный инвентарь и рюкзаки из `Inventory(METRO)`, мобы/трупы из `metrocraft.jar`, декоративные блоки из `StilianMetro.jar`, гермодвери и прочие механики старого модифицированного Flan.
- Рецепты выживания и точное воспроизведение старого баланса/анимаций/отдачи.

Старые `.class` несовместимы с 1.12.2 и не подмешиваются в сборку.

## Сборка JAR

Нужны **JDK 8** (не Java 17/21) и доступ к Maven Forge, Maven Central, Gradle и серверам загрузки Minecraft.

Linux/macOS:

```sh
./gradlew --no-daemon build
```

Windows:

```bat
gradlew.bat --no-daemon build
```

Результат после успешной сборки: `build/libs/metrocraft-port-1.12.2-1.0.0.jar`. Задача `build` также выполняет reobfuscation для запуска в обычном Forge.

Есть workflow `.github/workflows/build.yml`: он проверяет ресурсы, собирает JAR на Java 8 и публикует его в артефакт `metrocraft-port-1.12.2` успешного запуска. Зелёная сборка не заменяет проверку в игре.

## Установка

1. Установите Minecraft **1.12.2** и Forge **14.23.5.2860**.
2. Поместите **собранный** `metrocraft-port-1.12.2-1.0.0.jar` в `mods` клиента и сервера.
3. **Не кладите исходные моды 1.7.10 в `mods` 1.12.2**; папка `Flan` для нового мода не нужна.
4. Откройте творческий инвентарь и найдите три вкладки. Для проверки в выживании выдайте оружие/патроны через творческий режим или `/give @p metroport:ak74` и `/give @p metroport:5x45 64`.

## Обновление ресурсов и проверки

Для обычной сборки Python не нужен: сгенерированные ресурсы уже в репозитории.

```sh
python3 tools/import_content.py
python3 -m unittest discover -s tests -v
```

Импортёр читает исходный ZIP в памяти, не исполняет старые классы, проверяет ссылки на иконки/звуки и формирует имена ресурсов в нижнем регистре. Проверки охватывают каталог, ссылки, локализации, модели и воспроизводимость импорта; это **не игровые тесты**.

Сценарий ручной проверки клиента и выделенного сервера: [docs/TESTING.md](docs/TESTING.md).
Права на исходные ресурсы: [THIRD_PARTY.md](THIRD_PARTY.md).
