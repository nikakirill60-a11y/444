Текущая сборка v2 использует +2 ствола только как декор и всегда 2 патрона.
Исходник ниже оставлен лишь для истории; сборка по умолчанию запрещена.
Если старый JAR установлен, удалить его из mods клиента и сервера.

АРХИВНОЕ ОПИСАНИЕ ОТМЕНЁННОГО v1:

METRO DUPLET BRIDGE 1.0.0 / Minecraft 1.12.2 Forge + MWF fix1

Установить metro-duplet-bridge-1.0.0.jar в mods/ вместе с неизменённым
modularwarfare-shining-2024.2.4.6f-fix1.jar и общим контент-паком Дуплет+Убойник.
На выделенном сервере переходник и контент-пак тоже должны быть установлены.
Рекомендуется одинаковая сборка на клиенте и сервере; логика переходника серверная.
Мод не включён внутрь ZIP контент-пака и не заменяет MWF.

Переходник перехватывает штатные события MWF установки/снятия обвеса Дуплета.
С модулем metro_duplet_extra_barrels предмет меняется на metro_duplet_4
(вместимость 4), без него — на metro_duplet (вместимость 2).
Изменение выполняется отдельно для конкретного ItemStack, не для общего GunType.
Глушитель, удлинитель и +2 занимают один слот barrel и взаимно исключаются.

ВАЖНО: любые изменения обвесов Дуплета разрешены только при ammocount=0,
после завершения активных задач перезарядки/выгрузки. Сначала выгрузите патроны
штатным действием MWF. У загруженного оружия операция будет отменена.
Это сознательное безопасное ограничение v1, а не автоматический возврат лишних пуль.
Если нет места для снятых деталей, операция отменяется целиком. Предметы
не выбрасываются на землю и не исчезают. Снятие всех обвесов — одна транзакция.
Инвентарь и курсор обрабатываются на копиях; запись только после всех проверок.
Сохраняются исходные NBT, skinId, имя/прочность и сериализуемые ForgeCaps.
Остальные пушки, в том числе Убойник, переходником не обрабатываются.

Совместимость привязана к загруженному пользователем закрытому fix1 JAR.
Проверки модульной логики используют реальный API WeaponAttachmentEvent этого
JAR, но Minecraft/Forge окружение в тестах заменено тестовыми двойниками.
Полный запуск Minecraft и совместная работа с другими модами не проверены.
При ошибке операции мод отказывает в изменении и пишет в серверный лог.
Закрытый JAR не изменяется, coremod/ASM-патчи не используются.

Исходник: addons/mwf-duplet-bridge/src/main/java/ru/metrocraft/duplet/DupletBridge.java
Сборка: tools/build_duplet_bridge.py. Требуются Java, ECJ, Java-8 boot API
и выбранный оригинальный MWF JAR (SHA-256 проверяется сборщиком).
Тестовые Forge/Minecraft ABI-классы находятся только в tests_duplet/java;
они НЕ входят в готовый JAR. Выпускаются только два собственных .class файла,
mcmod.info, манифест и эта инструкция. Никакие чужие игровые классы не поставляются.
