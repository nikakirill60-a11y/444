# MinETRO — исправления арсенала v12 + инвентарь dev42

## Исправления
1. **Режимы огня.** Настоящий enum `WeaponFireMode` в закрытом MWF содержит SEMI/FULL/BURST, а не AUTO. Во всех 29 конфигах `auto` заменён на `full`; прочие режимы сохранены. Дополнительный Java-тест выполняет `fromString` именно исходного JAR и подтверждает, что старый `auto` возвращает null, а все новые значения корректны. Это установленная ошибка конфигурации; без crash-report нельзя утверждать, что устранены любые возможные причины вылета.
2. **Общий атлас убран.** `metro_native_atlas.png` удалён из всех трёх категорий и больше нигде не назначен. Оружию, магазину и обвесу назначены собственные PNG и перенесённые UV. Никаких повторов текстуры всего арсенала под новыми именами: в файле остаются лишь материалы конкретного предмета. MWF привязывает один skin к предмету, поэтому если модель состоит из нескольких исходных материалов, они лежат на её собственном небольшом листе, а не в общем атласе всех пушек. Главные PNG восстановлены из исходников; для уже запечённых повторяющихся материалов сохранены прежние фрагменты, без выдуманной «детализации».
3. **Калаш.** Исправлены координаты общего атласа, ошибочно использованные с отдельной картинкой. У обычного Калаша родной материал; у Армейского — `Army Kalash/wpn_aka.1024.png` с корректным размещением UV и сохранёнными материалами обвесов. Геометрия и обвесы не заменены. Предыдущее предположение о несовместимости самих развёрток было неверным: проблема была в преобразовании координат атласа.
4. **Сталлион.** Теперь принимает только собственный съёмный магазин `modularwarfare:metro_stallion_ammo` на 7 патронов `metro_bullet_magnum`, а не внутреннее заряжание револьвера. Есть перемещение магазина и затвора, отдельная временная шкала полной перезарядки; статический магазин из корпуса удалён. Оригинальная нижняя крышка магазина сохранена; скрытый внутри рукояти корпус магазина добавлен как адаптационная геометрия (12 треугольников), а не выдан за исходный объект.
5. **Пропавшая верхняя часть.** Загрузчик MWF хранит примитивы узла в Map по имени материала. Раньше два больших фрагмента Сталлиона имели один ключ и один заменял другой. Каждому примитиву теперь дан уникальный ключ; сохранены все 30648 исходных треугольников, включая верх/прицельные детали. Такая проверка распространяется на все glTF пака.
6. **Вики.** Добавлены все четыре новые пушки, два новых магазина, актуальные числа баланса и совместимость. Редкости берутся из `inventory_balance.json`, показаны цветными метками; есть фильтр редкости. Всего 29 MWF-пушек + 3 прежних предмета оружия. У существ и мутантов искусственные редкости не назначаются.

## Установка
Сделать резервную копию мира. **Перед обновлением разрядить старый Сталлион**: его прежнее внутреннее хранилище больше не является источником патронов; автоматическая NBT-конвертация не выполняется.

- Заменить ZIP полного арсенала в `.minecraft/ModularWarfare/` на `Metro_Full_Arsenal_MWF_fix1_v12_separate_textures.zip`. Старые полные ZIP/распакованные копии убрать, иначе будут дубли ID.
- Заменить MinETRO/MetroPort в `mods` на `metrocraft-port-1.12.2-1.13.0-dev.42.jar` из релиза `minetro-inventory-dev42`. Здесь профиль нового магазина: 250 г, 1×2 клетки. Компактная сетка и прочие профили не изменены.
- **MWF metro7 оставить прежним.** Нового исполняемого кода для этих исправлений не требуется; CI повторно собирает и сверяет SHA уже выпущенного metro7. Не ставить два MWF JAR одновременно.
- Обновление нужно на сервере и у всех игроков.

## Граница проверки
Проверяются ссылки/ID/UV, исходные позиции/нормали/индексы/таймлайны старого оружия, отсутствие общих текстур, все реальные enum режимов, многопримитивная геометрия, оба Дуплета, механика и поза Ашота. Нативные тесты выполняются на API-фасадах. **Minecraft/Forge/OpenGL не запускались**: ручная проверка хвата и перезарядки в игре всё ещё обязательна. Если вылет останется, нужен свежий `crash-reports` или `logs/latest.log` с версией пака.
