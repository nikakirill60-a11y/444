# BlackRazid — модули dev.9

Это часть общего незавершённого расширения, **не полный перенос оружейных моделей/анимаций**.
Восстановлены 28 исходных item-классов, девять классов старого инвентаря/GUI/фильтров,
28 родных PNG и два дополнительных звука. 67 оригиналов с Drive ID, размером и SHA-256
перечислены в `tools/blackrazid-reference/modules-source-files.json`.

## Использование

1. Возьмите собственное оружие `[BlackRazid]` в основную руку. Детали `[BlackRazid]`
   находятся во вкладке «Оружие»; детали прежних MCMOD/Flan не подходят.
2. Положите нужную деталь в хотбар или открытые строки Metro-инвентаря.
3. Дождитесь завершения перезарядки/выстрела и нажмите **M** (настраиваемая клавиша модификаций).
   Курсор и крафтовая сетка должны быть пусты.
4. Значки справа от гнезда — совместимые детали. Кнопка устанавливает **реальный предмет из инвентаря**,
   а не создаёт улучшение за ресурсы. Слева отображается установленная деталь; наведите мышь для названия.
5. «Снять» возвращает **тот же предмет со всеми его пользовательскими NBT**, только в свободную доступную ячейку.
   При отсутствии места операция отклоняется: деталь не выбрасывается, не теряется и не дублируется.
   Для замены сначала снимите старую деталь. Creative тоже расходует настоящий предмет при установке.

Россыпь, заряженные магазины и установленные модули записаны раздельно в самом стеке оружия.
Они переживают сохранение/передачу предмета; нет общего статического инвентаря на все стволы/игроков.
Сервер проверяет окно, текущую руку/ячейку, живого не-spectator игрока, совместимость и наличие предмета.
Стрелять/накачивать/перезаряжать через открытый экран модификаций нельзя.

## Реальные эффекты из исходных классов оружия

| Детали | Эффект |
|---|---|
| Glushak / VsvGlushak | Родной приглушённый звук на поддерживаемом оружии; Saiga/Ashot/Uboinik используют `saiga_closeshoot` с исходной громкостью |
| Butt / UbludokButt / PodonokButt | Отдача соответствующего ствола 0,4 |
| DupletButt / DupletPriklad | Отдача «Дуплета» 1; две детали не складываются в бесплатный дополнительный бонус |
| Barrel | +1 к урону Revolver/Podonok/Preved; у Preved скорость пули становится 10 |
| UboinikBarrel / DupletBarrel | Исходный разброс 70; у «Дуплета» скорость дроби 4 |
| QuadBarrel | Четыре места под патроны, 16 дробин за **два** патрона, скорость 4 |
| AutoFire | «Абзац»: задержка 4 вместо 7 и родной `abzac_fastshoot` |
| AbzacGlushak | «Абзац»: отдача 2 вместо 3,2; без выдуманного тихого звука |
| PodonokGas | «Подонок»: задержка 3 вместо 5 |
| RailgunKon | «Рельса»: задержка 8 вместо 20 |
| RailgunAkk | Предел заряда 60 вместо 40; завершённая накачка даёт 10 вместо 5 |
| GatlingBarrel | Задержки 2/3/4 вместо 3/4/5 по исходным трём диапазонам взвода |
| GatlingButt / GatlingGiro | Отдача 0,5 / 0,4; вместе 0,3; без них 0,6 |
| GatlingMotor | Автовзвод до 400 и отсутствие расхода взвода при выстреле; патроны по-прежнему расходуются |
| VentilGlushak | Отдача Ventil 0,4, Preved 0,8; отдельный выдуманный звук не добавлен |

QuadBarrel нельзя снять при трёх/четырёх оставшихся патронах: сначала уменьшите боезапас до двух.
Старое безусловное обрезание боезапаса при снятии не копируется. Выстрел с QuadBarrel требует два патрона;
исходная ошибка с возможным отрицательным остатком после последнего одиночного патрона исправлена.
Если сервер не создал ни одной пули, боезапас/взвод не списываются.
**AshotButt не имеет отдельного баллистического бонуса в исходном классе.** Он устанавливается/сохраняется,
но визуальная форма приклада ожидает родную модель: не приписан выдуманный бонус отдачи.

## Явные адаптации и ограничения

- Сохранены пять исходных индексов гнёзд, в том числе Laser в гнезде 0 у Duplet и ствол в 0 у Gatling.
  У AKSU исходный GUI не имеет гнезда глушителя, несмотря на оставшуюся звуковую ветвь gun-класса.
  Ognemet/Velopal не получили выдуманные гнёзда.
- Старые общие категории допускали бессмысленные детали от чужих стволов (например RailgunAkk в Gatling).
  В порте категория дополнительно ограничена подходящим оружием/исходной рабочей ветвью.
  Полная матрица — `blackrazid_module_fittings.json`; автоматическая проверка сверяет её с родными фильтрами.
- Оптика действует через локальный FOV при удержании **левого Alt**: коллиматор 1,5×, малая оптика 2×,
  Optica/TiharOptica 4×. Это **явная адаптация**, не утверждение о переносе старых линз/масок/моделей.
  Пользовательское значение FOV в настройках не перезаписывается.
- Laser даёт ограниченную 32 блоками клиентскую красную точку на поверхности, с проверкой глубины.
  Это **визуальная адаптация**, не исходный multipart-лазер и не бонус точности/урона.
- Оружие/магазины/детали пока используют исходные инвентарные иконки вместо полного набора multipart-моделей.
  Родные меши, анимации, интерфейс старого образца и игровая/визуальная приёмка остаются незавершёнными.
- Прежние позы/рендереры, в том числе одобренный револьвер, не редактировались.
  Исключённые общие обработчики/1000 HP не подключены.

## Проверки

Добавлены проверки исходных хешей и категорий, локализации/воспроизводимости, NBT,
доступного инвентаря, заполненного инвентаря, повторного снятия, чужого окна/руки/ячейки,
клиента/spectator/смерти, неверных размеров стеков/индексов, фактической задержки стрельбы,
четырёхствольной зарядки/двойного расхода, отказа spawn, взвода Gatling и завершённой зарядки Railgun.
Тесты используют управляемые миры/игроков, **не настоящий запущенный Forge-клиент/сервер**.
