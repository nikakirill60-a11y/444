# Исправление вылета dev.12 — LWJGL 2

По присланному crash report исключение происходит в
`NativeWeaponRenderer.renderByItem`, при чтении `GL_CURRENT_COLOR`:

> Number of remaining buffer elements is 4, must be at least 16.

Это ошибка мода, а не причина требовать удаления OptiFine/других модов или замены видеокарты.
Буфер создавался на четыре float-компонента RGBA. В Minecraft 1.12.2 / LWJGL 2 буферная перегрузка
`GL11.glGetFloat` проверяет **не менее 16 оставшихся float**, независимо от фактических четырёх результатов.
Исключение возникает до запроса к драйверу.

## Что исправлено

- Оружие, широкие пути и тоннели используют общий `GlStateBuffers.colorQuery()` — новый независимый
  прямой буфер на 16 float для каждого сохранения состояния.
- Восстановление RGBA читает абсолютные `get(0..3)`, без `flip()`: OpenGL не сдвигает позицию этого буфера.
- Проверены все буферные `glGetFloat` в клиентском коде. Скалярный запрос размера лазерной точки
  использует другую перегрузку и не требует исправления.
- Добавлены три Python-регрессии и четыре JUnit-регрессии. JUnit воспроизводит исключение на старом
  буфере через **реальный `org.lwjgl.BufferChecks`**, затем проверяет новый, native byte order,
  абсолютное чтение RGBA и независимость вложенных сохранений.
