Исходник `eea85f91ab171d8bea42946d636c2c3949a2df4c`, production deployment
`dpl_pXMoiW1RDjAZoA8G4R58P8bnCLSq`, READY / PROMOTED, canonical alias assigned.

## Что сделать владельцу

1. Открыть кабинет на компьютере в Chrome/Edge, войти как Cotuna. Если страница
   открыта давно — обновить её и войти заново.
2. Внизу в «Загрузить MinETRO dev» выбрать распакованную папку данных игры,
   внутри которой лежит mods. Допускается экземпляр с вложенной .minecraft.
3. Задать уникальное имя версии, нажать «1. Проверить папку», затем
   «2. Загрузить изменения». Не закрывать вкладку во время загрузки.
4. Проверив сборку и результат загрузки, отметить подтверждение и нажать
   «3. Разрешить скачивание этой версии».
5. В отдельном лаунчере 0.6 обновить статус доступа и установить dev.

Не требуется ZIP, Python, service-role ключ или передача пароля агенту. Браузер
загружает блоки напрямую в приватный Storage, не через лимиты Vercel Functions или
Drive connector. При обрыве/истечении сессии повторно выбрать папку; уже принятые
блоки проверяются по инвентарю и не загружаются повторно. Подготовка хеширует всю
папку локально, но сеть повторно передаёт только отсутствующие блоки.

## Права и безопасность

Миграция `202610300006_browser_publisher.sql` применена LIVE под именем
`owner_browser_file_publisher`. Отдельная publisher-роль назначена только
проверенному UUID Cotuna `c3104601-ba41-4776-9c60-d8c1996f97ef` после проверки
никнейма, подтверждённой почты, отсутствия удаления/блокировки. Inbox admin не
получает эту роль автоматически. Клиент не может менять таблицу назначений.

Storage: только INSERT/SELECT immutable chunks у publisher; UPDATE/DELETE не
разрешены. Чтение игроками по-прежнему требует approved и точного присутствия
блока в активном манифесте. Wrapper RPC проверяет отдельную роль и явную фразу
подтверждения, затем использует прежние проверки версии/полноты. Черновая загрузка
сама по себе не активирует релиз. Скрипт веб-страницы не содержит секретов.

Инкрементальный SHA256 — vendored @noble/hashes 1.8.0 (MIT), esbuild 0.25.12;
происхождение/контрольная сумма в website/vendor/SHA256_SOURCE.json. Память
ограничена блоком 8 МиБ, большой JAR целиком в память не читается. Локальные миры,
options, screenshots, packv4 и mod_config не читаются для публикации. Конфиги
публикуются только как начальные значения (seed), как в протоколе 0.6.
