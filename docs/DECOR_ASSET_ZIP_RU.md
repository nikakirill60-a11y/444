# ZIP декора — гермоворота, двери, лампы

[Скачать MinETRO_Decor_Germo_Doors_Lamps_v1.zip](../downloads/MinETRO_Decor_Germo_Doors_Lamps_v1.zip)

Отдельная выгрузка **75 объектов** существующего METRO_MOD-порта:

| Категория | Количество | Движение геометрии |
|---|---:|---|
| Гермоворота/ворота | 17 | Да |
| Обычные двери | 27 | Да |
| Лампы/светильники | 31 | Нет; переключается свет |

Внутри: обычные OBJ + MTL со ссылками на общие PNG, анимационные матрицы
в `animation.json` для каждой модели, исходные OBJ.GZ/профили ресурсов Forge,
справочные Java-классы движения/рендера/освещения, нумерованный CSV-каталог,
инструкция и манифест SHA-256. Для дверей/ворот экспортированы 65 матриц на деталь;
выборки не пересчитывались, кроме эквивалентного переноса из `move` шести старых ворот.
У ламп не придумана отсутствующая механическая анимация.

**Это архив ассетов, не готовый самостоятельный мод или обычный ресурспак.**
OBJ не хранит анимацию: для её воспроизведения в стороннем редакторе нужно
прочитать `animation.json`. Распаковать весь архив, чтобы относительные
ссылки MTL на текстуры сохранились. Java-классы — справка для интеграции,
не полный компилируемый проект. Оружия, мебели, ящиков, рубильников нет.

`structure/mls_vorota_l06` исключены: отсутствует обязательная исходная деталь add2.
Авторство и условия прав исходных материалов не меняются.

Проверки: **6/6** `tests/test_decor_asset_bundle.py` на реальном ZIP:
точный набор объектов, побайтная сохранность native-ресурсов и геометрии/UV OBJ,
ссылки OBJ → MTL → PNG, матрицы/посадка, CRC всех PNG и SHA-256 всех файлов.
Повторная сборка дала побайтно идентичный ZIP. Minecraft/OpenGL не запускались.

Сборка без дополнительных зависимостей:

```sh
python tools/package_decor_assets.py
python -m unittest discover -s tests -p test_decor_asset_bundle.py -v
```
