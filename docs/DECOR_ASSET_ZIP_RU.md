# ZIP декора v2 — текстуры рядом с моделью

[Скачать v2 с локальными текстурами](../downloads/MinETRO_Decor_Germo_Doors_Lamps_v2_local_textures.zip)

**Исправлено по просьбе пользователя:** у каждого объекта все PNG лежат
в той же папке, что OBJ и MTL. Материалы используют только имена файлов,
без `../` и ссылок на общий каталог. Папку одного объекта можно переносить отдельно.

75 объектов существующего METRO_MOD-порта:

| Категория | Количество | Движение геометрии |
|---|---:|---|
| Гермоворота/ворота | 17 | Да |
| Обычные двери | 27 | Да |
| Лампы/светильники | 31 | Нет; переключается свет |

Пример содержимого одной папки:

```text
objects/01_Germo_Gates/metromod_germo_1/
  part_00.obj
  part_00.mtl
  metal34_balka_02.png
  metal_trub_tonnel.png
  animation.json
```

Для составных объектов все части `part_XX.obj/mtl` находятся там же.
Общие PNG намеренно продублированы по папкам объектов; при конфликте одинаковых
имён разных изображений добавлен короткий SHA-суффикс. Изображения не перекодировались.

Сохранены нумерованный CSV-каталог и справочный код движения/освещения.
OBJ, UV, нормали и 65 матриц каждой детали сохранены из v1 без пересчёта.
Из `animation.json` убраны только ссылки на альтернативные Forge-меши `.obj.gz`;
для воспроизведения используются локальные OBJ. Происхождение вынесено в манифест.

Общий runtime-каталог `assets` из v1 не включён: для этих OBJ он больше не нужен.
Если требуются исходные профили/коллизии Forge и OBJ.GZ, они остались
в [прежнем v1](../downloads/MinETRO_Decor_Germo_Doors_Lamps_v1.zip).

**Это архив ассетов, не самостоятельный мод или обычный ресурспак.**
OBJ сам не хранит анимацию: для воспроизведения в редакторе нужно импортировать
матрицы из `animation.json`. У ламп не придумано отсутствующее механическое движение.
Java-классы — справка для интеграции, не полный компилируемый проект.
Оружия, мебели, ящиков, рубильников нет. Неполные `structure/mls_vorota_l06`
по-прежнему исключены из-за отсутствующей обязательной детали add2.
Авторство и права исходных материалов не меняются.

Проверки: **6/6** `tests/test_decor_local_textures.py` на настоящем ZIP:
все 75 объектов, локальные ссылки OBJ → MTL → PNG, побайтная сохранность
геометрии/UV/изображений и матриц, SHA-256 каждого файла. Каждая папка объекта
скопирована отдельно во временный каталог без общего `assets`: все зависимости найдены.
Повторная сборка дала побайтно идентичный ZIP. Minecraft/OpenGL не запускались.

Сборка без дополнительных зависимостей:

```sh
python tools/repack_decor_local_textures.py \
  --input downloads/MinETRO_Decor_Germo_Doors_Lamps_v1.zip
python -m unittest discover -s tests -p test_decor_local_textures.py -v
```
