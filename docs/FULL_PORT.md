## Не хватает исходных ресурсов

Классы оружия ссылаются на `LastDays/models/sprites/SpriteShoot`, `SpriteShoot2` … `SpriteShoot8`, которых нет ни в одном предоставленном архиве. Они не подмешиваются из посторонних модов и не объявляются перенесёнными. Для точного воспроизведения вспышек требуются эти файлы либо явно согласованная замена. Полный список: `geometry-report.json`.

## Что означает «готов полный перенос»

1. Все строки с незавершёнными механиками реализованы или пользователь явно согласовал отличие.
2. Исходные ресурсы проверены на доступность и права; отсутствующие внешние зависимости перечислены, а не молча заменены.
3. Клиент и выделенный сервер реально запускаются на Java 8 / Forge 2860.
4. Пройден ручной сценарий `TESTING.md`, в том числе сетевые действия, сохранение, смерть, смена измерений и попытки дюпа.
5. Проверены визуальные масштабы и положение всех моделей, не только количество деталей в JSON.
6. Только после этого сборка называется полной, а не промежуточной.

Исходники для сверки восстановлены CFR 0.152 в `tools/legacy-reference`. Это справочные материалы 1.7.10; их наличие не означает, что старые классы автоматически работают на 1.12.2.
