# MinETRO dev35 — многоклеточный инвентарь и редкости брони

## Что изменено

- Настоящая сетка **8×8**. Один предмет/стопка занимает прямоугольник заданного
  размера: **3×2**, **4×4**, **5×2** и другие. Ячейки внутри прямоугольника
  заняты; другой предмет туда положить нельзя. Это не просто увеличение иконок.
- ЛКМ — взять/положить/обменять; ПКМ — половина стопки/одна штука.
  Щелчок по любой занятой клетке выбирает весь предмет, а не отдельную копию.
- **R** поворачивает предмет на курсоре на 90°. Зелёная/красная подсветка
  показывает допустимость размещения. Контур не может выходить за границы.
- Сервер проверяет окно, ревизию операции, размеры, пересечения и реальный
  курсор. Клиент не отправляет содержимое предметов или NBT.
- Положение и поворот сохраняются в данных игрока. Сам предмет остаётся
  единственной исходной стопкой в `InventoryPlayer`; NBT MWF/патроны/NoDrop
  не переносятся в новую самодельную копию.
- Базовая грузоподъёмность **10 кг**; сумки **+10/+20/+30 кг**; броня **+2 кг**.
  Рюкзаки не добавляют клетки. Ограничение массы dev34 сохранено.
- Редкости явно назначены **всем 110 позициям раздела брони**, включая ПНВ.
  Для парных шлема/брони одного комплекта редкость одинаковая.
  Полная таблица: `ARMOR_RARITIES_DEV35_RU.md`. Защита и прочность не менялись.

## Примеры размеров (ширина × высота)

| Предмет | Размер |
|---|---|
| Револьвер, Ашот, Подонок, АКС-У, мини-огнемёт | 3×2 |
| Большинство автоматов и дробовиков | 4×2 |
| Ручной пулемёт, Превед, Хлопушка, Вентиль, Рельса | 5×2 |
| Обычная нагрудная броня / цельный костюм | 3×3 |
| Легендарная и мифическая нагрудная броня | 4×4 |
| Шлем / противогаз | 2×2 |
| Мачете | 1×3 |
| Аптечка | 2×2 |
| Малый / средний / большой рюкзак в вещах | 2×3 / 3×3 / 3×4 |
| ПНВ | 2×1 |
| Патроны и большинство мелких вещей | 1×1 |

Размер относится к **стопке**, не умножается на число патронов в стопке.
При экипировке предмет покидает сетку и занимает свой отдельный слот.
Основные 27 стопок Minecraft остаются физическими записями сетки; даже если
есть свободные клетки, 28-я отдельная стопка в ней не создаётся.
Два слота стволов, слот ближнего боя, остальное снаряжение и быстрый доступ
остаются отдельными, как в dev34. Сундуки и стандартные внешние окна не
превращены в Tetris: для новых вещей в обычных ячейках игрока проверяется,
хватает ли места в его сетке.

## Старые миры / предметы из сторонних модов

При первом открытии вещи автоматически раскладываются без удаления.
Если всем не хватает места, лишние **остаются исходными стопками**, а кнопка
«Забрать вне сетки» выдаёт их по одной на пустой курсор. Обратного помещения
в переполнение нет. Новое обычное пополнение не должно использовать
переполнение как дополнительные клетки. Когда место освобождается,
ожидающие вещи автоматически занимают его.

Старое внутреннее содержимое BlackRazid-рюкзаков, как в dev34, доступно
только на выдачу. Эта кнопка появляется после разбора переполнения сетки.
Команды/прямые записи неизвестных модов могут обойти обычные окна; такие
вещи тоже сохраняются и попадают в выдачу, а не удаляются.

## Установка и ручная приёмка

1. Резервная копия мира. Заменить предыдущий MetroPort на dev35 **на клиенте
   и сервере**. Не устанавливать рядом две версии. MWF metro6 + пак v10 оставить.
2. I/E: проверить отображение при GUI Scale Auto/Small/Large, от 640×480.
3. Положить револьвер 3×2, повернуть на R у правой границы; положить броню
   4×4. Проверить границы, пересечения, обмен и выбор через любую занятую клетку.
4. Несколько раз взять/положить/разделить стопку, закрыть, переподключиться:
   количество, NBT, положение и поворот не меняются самопроизвольно.
5. Четыре 4×4 заполняют 8×8. Пятый предмет не входит. Проверить старый мир
   с большим количеством вещей: выдача переполнения, отсутствие новых вложений.
6. Проверить подбор с земли и перенос из сундука при нехватке клеток/веса,
   получение вещей командами, смерть/keepInventory/NoDrop и смену измерения.
7. Два ствола 1/2, мачете 3, часы, ПНВ, фонарь, сумка и броня: функции dev34
   сохранены. Для MWF проверить стрельбу/ADS/перезарядку/обвесы/перезаход.
8. Проверить цвета брони по таблице и одинаковую редкость шлема/нагрудника.

Управление сеткой — щелчками. Vanilla shift-click/drag-splitting не расширены
на многоклеточные карточки. При сетевой задержке дождаться обновления курсора;
устаревшие повторные операции сервер отклоняет и синхронизирует состояние.

Автотесты не заменяют Minecraft/Forge/OpenGL и проверку с настоящим MWF.
Живая игра и визуальная приёмка в этой среде не выполнялись.
