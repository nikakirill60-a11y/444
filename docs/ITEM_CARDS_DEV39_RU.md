# MinETRO dev39 — ID, эксклюзив и карточки предметов (TEST)

Forge 1.12.2. **Убрать старый JAR MetroPort и заменить новым. Не устанавливать рядом:** технический modid изменён, поэтому Forge больше не считает старый и новый файл одним модом.

1. Технический ID мода и зарегистрированных предметов/блоков теперь **`minetro`**. Название в списке модов — **MinETRO**. Заглавные буквы в modid Minecraft недопустимы. Добавлены Forge remapping для старых пространств `metroport` и `metrocraftport` на существующие новые записи, включая сущности/звуки. NBT и идентификаторы TileEntity, ключи сохранений и содержимое вещей не переписываются вручную. Ресурсы используют прежнее внутреннее пространство с лёгкими JSON/языковыми алиасами, без копирования всех текстур и без возврата удалённых моделей.
2. Новая редкость **«Эксклюзив» — розовая** (`#f27fbb`). В неё переведены только шлем и броня «Запал». Прежние размеры этих двух вещей, защита и прочность не изменены. Явное NBT `MetroRarity` по-прежнему имеет приоритет.
3. Информация находится **на самих карточках**, не только при наведении: название, настоящий registry ID, вес. Для оружия — загружено/ёмкость/запас и название доступного боеприпаса; для повреждаемых предметов — оставшаяся/максимальная прочность; для остальных — подходящие размеры или бонус грузоподъёмности. Неизвестная ёмкость обозначается тире, а не выдуманным числом. Чтение MWF выполняется без жёсткой зависимости и без записи в его NBT. Обозначение боеприпаса берётся из самого предмета: выдуманный калибр не подставляется.

Карточки увеличены; сама серверная сетка остаётся **8×8**, её клетки/позиции/пакеты и антидюп не меняются. На небольшом GUI видна часть сетки: колесо прокручивает по вертикали, Shift+колесо — по горизонтали; полосы прокрутки можно перетаскивать, в том числе с предметом на курсоре. R по-прежнему поворачивает вещь. В компактных слотах подписи уменьшены и обрезаются по ширине, полное имя/ID доступны в обычной подсказке.

4. `rem` (набор инструментов), `armorrem` и `remkomplekt` — **2×2**; `kanistra` — **3×3**. Их вес не менялся: ремкомплекты по 3 кг, канистра 6 кг.

Удаление дверей/ворот/стационарных ламп dev38 сохранено; шесть рычагов и переносной фонарь остаются. Редкости оружия dev36 сохранены.

**Перед загрузкой старого мира сделать резервную копию.** Клиент и сервер должны использовать одинаковую новую сборку. Minecraft/MWF здесь не запускались: remapping старого мира и вид/читаемость карточек на разных GUI scale требуют проверки в игре. Автотесты и проверка содержимого JAR не заменяют такую проверку.
