# MinETRO Launcher TEST 0.3 — аккаунты и свои скины

Подготовлены реальный Windows UI, клиент Supabase Auth/REST/Storage и SQL-схема.
**Живой Supabase пока не подключён** — доступ будет предоставлен позже.
Регистрация, вход и загрузка в облако в опубликованной версии отключены честно.
Выбор PNG и предпросмотр работают локально без аккаунта: «Мой профиль» → «Скин».

## Добавлено

* Регистрация по почте с ником и паролем, повтор пароля.
* Подтверждение почты кодом, повторная отправка и вход кода после перезапуска.
* Вход, выход, восстановление пароля по коду; после смены пароля запрос глобального
  выхода (отзыв refresh-сеансов средствами Supabase; access JWT живёт до истечения).
* Личный профиль и смена уникального ника.
* PNG 64×64 / 64×32 до 256 КБ; декодирование, нормализация и очистка метаданных.
* Steve / Alex и двумерный предпросмотр спереди/сзади с отдельными UV конечностей.
* Подготовлен приватный storage: один объект на пользователя и RLS своей строки.
* Пароли и сеанс не записываются на диск; после закрытия потребуется вход заново.
