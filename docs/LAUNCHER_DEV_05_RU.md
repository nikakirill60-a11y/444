# Отдельный тестовый лаунчер 0.5

- Выбор **MinETRO dev** / **MinETRO**. Публичный канал пока недоступен.
- «Запросить доступ» вызывает существующий серверный RPC. Заявка попадает в
  административную очередь кабинета; Cotuna подтверждает/отклоняет её на сайте.
- «Обновить статус» получает статус своего аккаунта, не локальный флаг.
- При одобрении, но без опубликованного архива, установка остаётся выключенной.
- Ник в профиле только для чтения. Есть ссылка на кабинет сайта.
- Автопоиск последних публичных GitHub-релизов отключён. Кеш канала не используется
  для разблокировки. Новые версии не добавляются автоматически.

## Защищённая выдача

Применена миграция `202610300004_private_dev_distribution.sql`:
закрытый bucket `dev-packs`, таблица релиза без клиентских прав на публикацию,
RPC `get_dev_release()` с обязательным серверным approved и Storage RLS,
проверяющий тот же статус и точный ключ опубликованного объекта.
Администратор заявок не получает права публиковать релизы.

Клиент подменяет URL из серверного манифеста на адрес приватного bucket своего
Supabase-проекта. Bearer остаётся в Accounts; редиректы не выполняются.
Перед установкой/запуском и перед открытием загрузки повторно проверяется сервер.
Это контроль выдачи, не DRM: уже выданные файлы нельзя отозвать с компьютера.

**Архив пока не опубликован.** Исходный Drive MinETRO.zip — 3 712 211 685 байт.
Не завершены инспекция архива/хеши модов и подключение подходящего защищённого
хранилища для такого размера. Bucket создан как основа политики, это не гарантия,
что текущие лимиты Supabase допускают файл 3.7 ГБ. Не делать Drive публичным.
После инспекции и явного принятия владельцем нужен точный манифест, хеши,
проверенные лимиты хостинга и отдельная публикация. MetroEdit не добавлять;
сохранить WorldEdit, творческий режим, декор, карты и сохранения.

## Проверки

CI Windows выполняет 15 базовых + 6 release-протокольных + 12 account + 8 dev
сценариев; 4 Python-теста. UI smoke использует подставной аккаунт и проверяет
блокировку до входа, none → pending → approved без архива, закрытый публичный
канал и выход. Скриншоты HOME/PUBLIC/PROFILE из этого smoke, не реальный вход.
SQL отрицательные проверки: `launcher/supabase/tests/private_dev_distribution.sql`.
Реальную установку большого архива и Minecraft этот тест не подтверждает.

Результаты сборки и SHA256 находятся в артефакте **MinETRO-Launcher-Windows**
соответствующего GitHub Actions запуска. Workflow dispatch публикации из этой
сессии отклонён GitHub (403); обычный CI сохраняет отдельный тестовый артефакт,
не публикует его в автообновления и не меняет действующий лаунчер.
