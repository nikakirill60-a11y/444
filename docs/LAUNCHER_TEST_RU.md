# MinETRO Launcher TEST 0.2 — Windows x64

Реальная Windows-оболочка с новым оформлением: фон станции метро, боковая
навигация, большая контекстная кнопка, отдельные страницы настроек и информации.
**Полный модпак пока не подключён.** Один MinETRO.jar не заменяет MWF, packv4 и
остальные ресурсы; установка и запуск при `archive: null` недоступны.

## Использование

Распаковать **весь** ZIP и открыть `MinETRO-Launcher-Test.exe`. Не удалять соседние
`Assets`, `third-party` и `channel.test.json`. .NET встроен, администратор не нужен.
EXE пока не подписан; Windows может предупреждать. Не отключать защиту Windows.

«Подключить сборку» открывает настройки. Полный доверенный архив подключается
через JSON-манифест по [инструкции автора канала](../launcher/MAINTAINER_RU.md).
Пользователь подтверждает источник; канал сохраняется локально и не обновляется
удалённо без согласия. SHA256 проверяет целостность, но не безопасность модов.

«Войти через Prism» подготавливает официальный portable Prism с проверкой SHA256.
Учётные данные вводятся только в Prism / Microsoft; оболочка не читает accounts.json
и не обходит лицензию Minecraft Java. Java 8 x64 настраивается в Prism.

Выбирать отдельную папку. Установка проходит через staging с последующим rename
в отдельный экземпляр Prism. Новая версия не стирает предыдущую; миры автоматически
не переносятся. Перед переносом нужна резервная копия. Повторная проверка не
перезаписывает настроенные руки/настройки. Полная инструкция и лицензии есть в ZIP.
