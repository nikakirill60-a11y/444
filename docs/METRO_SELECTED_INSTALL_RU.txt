ПКМ предметом по земле — установка, направление зависит от взгляда игрока.
Нужен воздух для ВСЕГО хода створок, иначе предмет не расходуется и блоки не меняются.
Модели разных размеров, включая очень широкие/высокие; сначала пробовать на пустой площадке.
Управление — redstone: сигнал открывает, снятие сигнала закрывает. Подвести провод/
рычаг/кнопку к краю конструкции (любой занятой ей ячейке), не обязательно к центру.
ПКМ по воротам напрямую их не переключает. Собственные донорские рубильники ещё не включены.
Невидимые ячейки резервируют ход, но не создают стену в открывшемся проходе.
Подвижные коллизии консервативные, с точностью 1/4 блока, не треугольник-в-треугольник.
При движении створки останавливаются перед живыми игроками/мобами; проверяется весь ход тика.
Разрушение створки/рамки удаляет принадлежащие ей части; предмет выпадает только у контроллера.
Поршни не перемещают части ворот. При незагруженной части конструкция не движется.
Состояние открытия, направление и принадлежность частей сохраняются между перезаходами.

Восстановлены оригинальные OBJ и diffuse-текстуры, направления/расстояния хода.
Скорость адаптирована к Forge (0.015 нормализованного хода/тик). Общие оригинальные
звуки открытия/закрытия уже имелись в dev24; это НЕ точное соответствие звуку каждой модели.
Normal/specular/emission донора и GLSL330 не подключены.

MetroPort 1.13.0-dev.21 — звуки, маска/ПНВ, медицинские материалы

1. Оригинальные звуки METRO_MOD
- Фляга: items/flyashka; аптечка MCMOD: items/med.
- Замена фильтра: mask/change_filter.vba, только после успешного завершения.
- Предупреждение часов-дозиметра: три оригинальных watch_timer_alarm по очереди.
  Прежний порог и однократность сохранены; BlackRazid-часы остались только временем.
- Ворота: оригинальные right_open/right_close адаптированы как общие звуки

  исходным шести моделям. Звук только при начале движения, не при зажатом сигнале
  или попытке открыть заблокированную конструкцию. Управление только redstone.
Старые события/файлы сохранены для совместимости; дублирование воспроизведения не добавлено.

2. Графика маски и ПНВ
- Оригинальная чистая текстура маски при надетом противогазе/защитном цельном костюме.
- Оригинальные google_tex и noise_tex для ПНВ: совместимое умножение маски и слабый
  движущийся шум. N по-прежнему переключает ПНВ, L — фонарь.
- Только первое лицо, живой игрок, не spectator, не меню/инвентарь/F1.
- Рисуется перед HUD; гамма, глобальный шейдер, трансформации рук/оружия не меняются.
- Это адаптация текстур через обычное наложение, НЕ полный GLSL 330 pipeline донора.
  Повреждённые стадии маски не включены: соответствие износу не выдумано.
Отключение в config/metroport-visuals.cfg, секция client, затем перезапуск клиента:
maskOverlay=false; nvgTextureOverlay=false; nvgNoise=false; nvgTint=false.
Для полного отключения новых экранных эффектов выключить все четыре параметра.
