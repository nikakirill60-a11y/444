# Full Arsenal v8 — пользовательский 3d.rar

Пак: `downloads/Metro_Full_Arsenal_MWF_fix1_v8_3d.zip`.
SHA-256: `e6b1aa6c10bbb3059db061167d12e12df2f76b3deb378defe6757da9f2a294f5`.
Размер: 93 423 032 байта. 25 отдельных gun ID (23 прежних + 2 новых).

## Что изменено

- **Мини-огнемёт — отдельное оружие `metro_ognemet_mini`**, не скин.
  Все четыре группы OBJ используют одну исходную текстуру огнемёта, отсутствующую
  в архиве, но найденную в tracked BlackRazid assets. UV проверены на текстурированном
  предварительном рендере, повторяющиеся UV разрезаны по границам тайлов.
  Добавлен отдельный предмет баллона `metro_ognemet_mini_ammo` ёмкостью 200.
- **Медведь — отдельный ID `metro_medved`** с моделью и текстурой из архива.
- Новый **общий лазер** `metro_mod_laser`: `att_lazer.obj` + `wpn_obves.png`.
  Обе группы материала накладываются одновременно, не как скины.
- **Общий коллиматор** `metro_mod_kolimator` использует точную OBJ-геометрию
  и текстуру прежнего коллиматора Убойника.
- На всех совместимых оружиях старые запечённые лазеры/коллиматоры остаются скрыты;
  вместо них отображается общая модель предмета, а не дублирующий меш.
- Убойник принимает общий лазер, ствол и глушитель. Личные версии убраны из каталога.
  Старый ствол также принимался Ашотом — его ссылка и крепление тоже перенесены.
- `wpn34_bigun.png` наложена на корпус Убойника в левой половине атласа.
  **Правая половина с отдельной текстурой патронов сохранена**, существующая UV-развёртка
  не сдвинута. Текстурированный браузерный рендер осмотрен.
- Радиатор Ублюдка добавлен отдельным мешем. Его UV разрезаны для повторения,
  текстура помещена в ранее прозрачный тайл общего gun-атласа с отступом 2 px.
  Все прежние пиксели вне этого тайла неизменны. Отдельная копия атласа не создаётся.

Исходные 12 файлов сохранены без изменения в `tools/mwf-3d/sources.zip`.
Хеши, коэффициенты/смещения, источник найденной текстуры и ограничения находятся
в `ARCHIVE_3D_UPDATE_MANIFEST.json` внутри пака.

## Что сохранено

Это точечное обновление **точно v7**, не пересборка из старого pre-mechanics-пака.
Исходные 23 модели/руки/анимации/буферы не перегенерированы; к Ублюдку лишь добавлен
отдельный буфер радиатора. Позиции/масштабы рук не подгонялись скрытыми компенсациями.
Исправленный магазин АК2012 и барабан револьвера, v6-энергомеханики,
переключение стволов Дуплета, существующие боеприпасы и OGG сохранены.

## Установка и миграция предметов

Нужен тот же **MWF fix1-metro4 JAR**:
`dc78d8251b98d82006489432d09fb98486df888b779aaf675a62987bc5160823` (SHA-256).
Пак v8 заменяет прежний Full Arsenal, **не ставить их рядом**.
Обновить одинаково на клиенте и сервере. Это content pack, не полная сборка Minecraft.

**До обновления сделать резервную копию мира и заменить старые обвесы в инвентарях:**

| Старый ID (удалён) | Новый общий ID |
|---|---|
| `metro_uboinik_laser` | `metro_mod_laser` |
| `metro_uboinik_suppressor` | `metro_mod_glushak` |
| `metro_mod_uboinik_barrel` | `metro_mod_barrel` |
| `metro_uboinik_collimator` | `metro_mod_kolimator` |

Автоматическая миграция NBT мира в этот ZIP не включена. Не обновлять единственную
копию мира с незаменёнными старыми предметами.

## Проверки и честные ограничения

- 7 Python-регрессий на настоящих v7/v8 ZIP: ссылки на ресурсы/принятые обвесы,
  сохранность исходных поз/анимаций/патронов/звуков, новые отдельные ID,
  конечность координат и границы буферов, UV, неизменность старых пикселей атласа.
- Offline Chromium/Armory открыл реальный ZIP с 25 оружиями. Пройден рендер
  от первого лица и orbit для Медведя, мини-огнемёта, Убойника, Ублюдка, Ашота,
  АК2012 и револьвера. На Убойнике/Ашоте включены новые общие обвесы.
  Нет JS-ошибок и HTTP-запросов. Скриншоты осмотрены.
- Повторная сборка дала побайтно идентичный ZIP/SHA-256.
  Дополнительно Armory 63/63 и Pose editor 22/22 Node-теста прошли.
- **Minecraft не запускался.** Крепления адаптированы равномерным масштабом
  и смещением по прежним габаритам креплений; это не доказательство идеальной
  посадки/ADS/совпадения хвата в игре. PIP/сетка/стекло прицела браузером не эмулируются.
- Мини-огнемёт пока использует существующую **bullet-based MWF-адаптацию,
  НЕ настоящий поток огня**. Исходная модель статична: анимация съёма её баллона
  не выдумывалась. Перезарядка хранит руки исходного огнемёта; внешний магазин скрыт.
- Медведь пока использует стартовый профиль дробовика/перезарядки Убойника:
  6 зарядов, buckshot. Это явно обозначенная первоначальная адаптация, а не
  реализация исходной пневматики/баланса Медведя. Модель без разделённых деталей,
  старые патроны и детали шаблона на неё не навешиваются.
- Правка камеры обоих редакторов уже включена в Armory v4 / исходники Pose editor
  (см. `MWF_GEOMETRY_V7.md`). v8 не вносит дополнительных фиктивных компенсаций.
- Регистрация на сайте опубликована ранее; отсутствие настроенного SMTP/проверки
  реального письма эта оружейная правка не устраняет.

## Воспроизведение

```sh
python -m pip install numpy Pillow
python tools/integrate_mwf_3d.py \
  --input downloads/Metro_Full_Arsenal_MWF_fix1_v7_geometry.zip \
  --output downloads/Metro_Full_Arsenal_MWF_fix1_v8_3d.zip
python -m unittest discover -s tests -p test_mwf_3d_update.py -v
npm ci --prefix tools/mwf-armory
npm run build --prefix tools/mwf-armory
PLAYWRIGHT_MODULE=/absolute/path/to/playwright-core/index.mjs \
MWF_CHROMIUM=/absolute/path/to/chromium node tools/mwf-armory/archive3d-smoke.mjs
```

Патчер намеренно проверяет SHA-256 входного v7 и откажется заменять произвольный
или более новый пак. Порядок ZIP и timestamps фиксированы.
