# Полный арсенал MWF: совместимость v2

Задача: подключить уже существующие обвесы. Новые модели пользователь пришлёт позже.

## Поставка

`downloads/Metro_Full_Arsenal_MWF_fix1_v2_compat.zip` — самостоятельная замена полного пака v1,
а не дополнительный пак поверх него. Установить один ZIP в `.minecraft/ModularWarfare/`,
предыдущий полный пак и отдельные паки Убойника/Дуплета убрать из этой папки.
Клиент и сервер должны использовать одинаковую версию. Перед заменой — резервная копия мира.
Закрытый MWF `modularwarfare-shining-2024.2.4.6f-fix1.jar` не изменяется;
SHA-256 выбранного JAR: `f91a5419cbc9e3cbd18f831e37c17aa2833d577142d324fed1ca14846ce95183`.

База — опубликованный `Metro_Full_Arsenal_MWF_fix1_v1.zip` из `dc4d1f8`,
SHA-256 `0403f8fced602d38ce21300edcc2779bc1b79403a0a48fab1fb5662d9614b915`.

## Добавлено

| Оружие | Существующие предметы |
|---|---|
| Дуплет | `metro_mod_laser` |
| Велопал | `metro_mod_laser` |
| АКСУ | `metro_mod_glushak` |
| Сайга | `metro_mod_glushak` |
| Убойник | `metro_mod_uboinik_barrel`, `metro_mod_optica_small` |
| Вентиль | `metro_mod_optica` |
| AKK | `metro_mod_optica`, `metro_mod_optica_small`, `metro_mod_kolimator`, `metro_mod_laser`, `metro_mod_glushak` |

Всего **12 связей, 7 оружий**. AKK получает совместимость семейства АК как дополнительная
модель пака; отдельный канонический набор обвесов для такого имени не заявляется.

Каждая связь содержит не только `acceptedAttachments`, но и запись `attachment`
в индивидуальном enhanced render-конфиге. Используется существующий OBJ с его собственной
текстурой (`sameTextureAsGun: false`), поворотом +Z → +X и ненулевым масштабом.
Посадка дульных модулей рассчитана по срезу ствола; оптика Убойника привязана к месту
текущего коллиматора, Вентиля — к месту текущей IR-оптики. ЛЦУ ставятся сбоку цевья.
Это новые приближённые настройки крепления, **не восстановленные оригинальные сокеты**.
Проверки Minecraft/OpenGL, точной посадки и доводки ADS пока нет.

## Намеренно не изменено

- Все OBJ, glTF, UV, PNG, атласы, иконки, звуки и существующие настройки креплений.
- Урон, боеприпасы, вместимости, режимы огня, позы, руки, ADS-позы и анимации.
- Дуплет: **2 патрона**, дополнительные стволы декоративные; companion/bridge отсутствует.
- Настройки кратности/ночного режима: «Оптика» пока не означает реализованные 4×,
  а добавление совместимости с IRNV не реализует ПНВ.
- Особые механики пневматики, Рельсы, автоадаптеров и Gatling.
- Радиаторы, клапаны, штык и иные отсутствующие модели не подменяются заглушками.

Исходный аудит: [Metro Wiki — Attachments](https://metrovideogame.fandom.com/wiki/Attachments).
Перечень новых связей и ограничения включены в `FULL_PACK_MANIFEST.json` и README внутри ZIP.
Две исторически пропущенные ветки (`Saiga/Glushak`, `Ventil/Optica`) перенесены из
`omittedSockets` в `compatibilityUpdate.resolvedOriginalOmissions`, поскольку теперь
они рисуются отдельными OBJ, а не отсутствующими ветками native-сцены.

## Воспроизведение и проверки

```sh
python tools/patch_full_mwf_compatibility.py
python -m unittest discover -s tests_mwf -p test_full_pack_compatibility.py -v
# Дополнительно — схема именно выбранного закрытого JAR:
MWF_JAR=/path/to/modularwarfare-shining-2024.2.4.6f-fix1.jar \
  python -m unittest discover -s tests_mwf -p test_full_pack_compatibility.py -v
```

Вход можно задать через `--source`, выход через `--output`; скрипт проверяет SHA базы и
запрещает перезапись входного ZIP. Тестовые пути задаются через `MWF_BASELINE_ZIP` и `MWF_COMPAT_ZIP`.
Тесты проверяют точный список изменений, все 12 связей, крепления, ссылки на ресурсы,
сохранность всех бинарных ресурсов/поз/баланса, идемпотентность и косметические стволы Дуплета.
JAR-проверка читает фактические поля классов, в том числе унаследованные TRS-поля attachment.
Ни один из этих офлайн-тестов не является игровым тестом.
