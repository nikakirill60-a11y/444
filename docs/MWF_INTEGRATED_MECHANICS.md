# Встроенные механики Metro MWF 1.0

Пользователь разрешил изменить выбранный закрытый MWF: накачка оружия, рабочие дополнительные
стволы Дуплета и звуки глушителей. Это отменяет прежнее решение о чисто декоративных +2 стволах.

## База и архитектура

- Входной MWF: ровно предоставленный `modularwarfare-shining-2024.2.4.6f-fix1.jar`,
  SHA-256 `f91a5419cbc9e3cbd18f831e37c17aa2833d577142d324fed1ca14846ce95183`.
- Пак: опубликованный v2 compatibility, SHA-256 `87a1c12a14543b022810da233d8db26548e7587d7b9cd804bd155712e624f6ec`.
- Нет переключения на другую версию публичного upstream. Сборщик меняет точечные места
  в **копии этого JAR**, сохраняет остальные классы, ресурсы, лицензии и существующий bootstrap.
- Дополнительный bridge/coremod не устанавливается. Исходный JAR не перезаписывается.
- Версия Forge-мода получает суффикс `-metro1` и строгую проверку версии второй стороны:
  исходный клиент не должен отправлять неизвестные новые пакеты изменённому серверу и наоборот.

`PatchMwf.java` выполняется только при сборке на JDK 17. В Minecraft поставляются helper-классы
Java 8 и изменённые исходные классы MWF, а не сборочный ASM-инструмент или тестовые заглушки.

## Реализованные правила

Удерживание **P**, переназначаемое в управлении: +20 давления/энергии каждые 10 серверных тиков.
Клиент отправляет только номер хотбар-слота. Сервер сам проверяет оружие, наличие персонажа,
выбранный слот, боезапас, перезарядку, время накачки и интервал запросов. Состояние находится
в NBT конкретного оружия, сохраняется при выбрасывании/загрузке мира, не зависит от магазина.
Накачка не добавляет патроны. Первоначально давление/заряд равны нулю.

- **Тихарь:** максимум 120, расход 8 на выстрел.
- **Хельсинг:** максимум 120, расход 18 на выстрел.
- Нормальное давление 100; превышение теряет 1 единицу/сек до 100. Урон зависит от давления,
  избыточное давление даёт до +20%. При нехватке воздуха выстрел блокируется.
- **Рельса:** 100 энергии, расход 8, батарея даёт максимум 150. Конденсатор уменьшает время
  накопления полного выстрела с 40 до 30 тиков. До полного накопления выстрел слабее.
- **Дуплет:** базовая вместимость 2; `metro_duplet_extra_barrels` даёт 4. Используется один ID
  оружия и динамический запрос вместимости по стеку, без изменения общей `GunType`.
  Один выстрел расходует один патрон. Залпы 2/4 и перепривязка ПКМ не добавляются.
- Обвесы Дуплета меняются атомарно только на разряженном оружии вне перезарядки. Снятый модуль
  не теряется при заполненном инвентаре; операция в таком случае отменяется.

Правила давления/энергии — явная игровая адаптация, не обещание идентичных оригиналу формул.

### Enhanced-сеть

В выбранной базе `PacketExpShot` расходует патрон и воспроизводит звук, а отдельные
`PacketExpGunFire` обрабатывают попадания. Поэтому патч проверяет **логический выстрел**
перед родным расходом, затем разрешает попадания только для этого стека и короткого окна
выстрела. Давление расходуется один раз, а не на каждую дробину. Повторные попадания по одной
цели ограничены количеством дробин. Множитель давления применяется к урону и бонусу в голову.
Для этих Enhanced-стволов также закрыт обход через старый пакет BASIC-выстрела.
Это дополнение к валидации исходного MWF, не новый полноценный серверный raycast/античит.

Динамическая вместимость заменяет 15 чтений `internalAmmoStorage` в загрузке/подтверждении
перезарядки, инициализации, HUD, Enhanced-рендере и ScriptAPI. Четыре чтения BASIC-анимаций
не меняются: механики выстрела этой поставки рассчитаны на Enhanced-оружие нашего пака.

## Звук

Существующие обычные выстрелы не меняются. Для совместимых глушителей создаются отдельные
OGG на основе записей пака: фильтрация, компрессия, короткий хвост и меньшая дальность.
Это **не оригинальные записи Metro с глушителем**. Штатный `isSuppressor` выбирает отдельное
событие в клиентском и серверном звуковых путях. Для накачки добавляются короткие аудиосигналы.
Дульный тормоз Абзаца и пламегаситель Вентиля/Преведа исправлены: не классифицируются как звуковые глушители.

## Проверки и ограничения

- JDK 17 компилирует runtime-код в Java 8; входные SHA проверяются.
- Изолированные JVM-тесты с явными фасадами Minecraft проверяют правила, разрешение
  выстрелов/попаданий, накачку, расход, утечку, батарею/конденсатор, независимую вместимость,
  возврат модулей, заполненный инвентарь, NBT и блокировки перезарядки.
- ASM проверяет счётчики вставок и корректность стеков изменённых методов через BasicVerifier.
- Ни один compile/test facade `net.*`, `io.*`, `com.*` не включается в результат.
- OBJ, glTF, UV, PNG, позы, руки и анимации сохраняются. Новая анимация насоса не придумана.
- Огнемёт, вращение Gatling, автоадаптеры, полноценные ПНВ/кратность оптики пока не реализованы.
- **Minecraft/Forge/OpenGL и реальная сетевая игра здесь не запускались.**

Сборка:

```sh
python -m pip install imageio-ffmpeg==0.6.0
python tools/build_mwf_mechanics.py --mwf-jar /path/to/selected.jar
```

Выход: изменённый MWF JAR, полный контент-пак v3, русская инструкция и JSON-отчёт с SHA/проверками.
Установить новый JAR вместо старого и v3 ZIP вместо предыдущего пака, одинаково на обеих сторонах.
