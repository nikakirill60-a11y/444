# MWF Pose Studio v1 — редактор положения рук

[Скачать готовую программу (ZIP, 4,42 МБ)](https://raw.githubusercontent.com/nikakirill60-a11y/444/arena/dcab859f-444/downloads/MWF_Pose_Editor_v1.zip)

Распаковать архив и открыть **MWF_Pose_Editor.html** в современном Chrome, Edge или Firefox. Установка EXE, Node.js и сервер не нужны. Работает без интернета; нужен WebGL2. Внутри уже есть **«Убойник v5»** для Minecraft 1.12.2 / закрытого MWF-Shining `2024.2.4.6f-fix1`. Сам JAR мода не включён.

## Возможности

- Настройка левой и правой руки по трём координатам и углам, общий масштаб каждой руки.
- Отдельные добавочные смещения для обычного хвата/ADS и перезарядки.
- Первое лицо, ADS, свободный 3D-осмотр с автоматическим подбором камеры.
- Просмотр полной перезарядки (встроенный пак: номинальные 8 секунд), выстрела, доставания и осмотра; пауза и промотка.
- Обычные и тонкие руки, загрузка скина PNG 64×64, подсветка выбранной руки.
- FOV и формат экрана; перемещение всего оружия с компенсацией конечного положения ADS.
- Просмотр трёх обвесов и количества патронов (не установка обвесов на предмет в игре).
- Отмена/возврат правок; проект `.pose-project.json` с исходным ZIP и настройками.
- **Экспорт установочного ZIP**: правки рук запекаются в glTF, правки положения оружия — в существующий render JSON. Новые неизвестные поля в игровой конфиг не добавляются.

Проект — не контент-пак. Чтобы перенести правки в игру, нажать **«Экспорт пака ZIP»**, полностью закрыть Minecraft, убрать старые ZIP/распакованные дубликаты с теми же предметами, установить новый `*_POSE_EDIT.zip` целиком в `.minecraft/ModularWarfare/` и перезапустить игру. На сервере нужен тот же ZIP. Редактор HTML не устанавливается в Minecraft.

## Границы точности

Это **не Minecraft и не рендерер, запущенный внутри мода**. Предпросмотр использует геометрию, текстуры, анимационные ключи и основную матрицу камеры пака. Освещение, динамическое покачивание/отдача, OptiFine/шейдеры, броня на руках, коллизии и серверная логика не воспроизводятся. Для сравнения кадров нужно выставить FOV и соотношение сторон как в игре. Свободный 3D-осмотр — не полноценный игровой вид от третьего лица. Между анимационными ключами возможны различия интерполяции при больших поворотах.

Проверка в настоящем Minecraft здесь не проводилась. Редактор **не исправляет OpenGL 1281** и не доказывает отсутствие этой ошибки в игре.

Поддерживаются Enhanced ZIP с текстовыми `.gltf`, встроенными буферами и отдельными стандартными узлами рук, как у данного «Убойника». Это не универсальный редактор всех паков. BASIC/OBJ, GLB, skin/joints, matrix вместо TRS узлов рук и экспорт CUBICSPLINE рук не поддерживаются. Отдельные изменения рук по установленным обвесам требуют игровой логики и не реализованы.

Скин используется только для предпросмотра; игра берёт скин игрока. При открытии проекта настройки камеры/просмотра и свой скин нужно выбрать заново. Изменения сохраняются только при сохранении проекта/экспорте, не автоматически.

## Проверки

- **20 Node-тестов**: загрузка реального встроенного ZIP, отсутствие изменений при нулевых смещениях, сохранение PNG/OGG/OBJ, обе разновидности рук, локальные XYZ-кватернионы, масштаб, idle/reload ключи, неизменность исходных данных, разделяемые sampler/accessor, статические руки, отказ CUBICSPLINE, проект, длительность 8 секунд, камера по независимым Python-матрицам.
- **Браузер Chromium 153 / SwiftShader**: реальное открытие одиночного HTML через `file://` с блокировкой HTTP, правки обеих рук, undo/redo, ADS, перезарядка, свободная камера, три обвеса, компенсация ADS и синхронизация полей, скачивание и повторный импорт проекта, скачивание и повторное открытие экспортированного ZIP, изменение размера окна. Ошибок JavaScript и HTTP-запросов не было. Скриншоты просмотрены.
- Экспорт непосредственно из браузера проверен `tools/verify_uboinik_pack.py` с **выбранным настоящим JAR** и его `GltfModelReader`: **13 узлов, 12 мешей; 41 файл, 6 патронов, 6901 треугольник, 5 предметов**. Добавленный файл — текстовый журнал редактора. Мод/JAR не изменяется.

## Исходники и сборка

```sh
cd tools/mwf-pose-editor
npm ci
npm test
npm run build
```

Исходный встроенный пак: `downloads/Metro_Uboinik_MWF_fix1_v5.zip`.

Результаты сборки:
- `artifacts/mwf-pose-editor/index.html` — один HTML без CDN/внешних скриптов;
- `downloads/MWF_Pose_Editor_v1.zip` — HTML, русская инструкция, лицензии Three.js и fflate.

Сборка в этой поставке: HTML **6 180 143 байта**, ZIP **4 419 090 байт**.

SHA-256 ZIP: `05b9280e3cdf1f5e12d9874345037689d05f6664e5e0c2c6a375db783e7a3ad7`.

Редактор не отправляет файлы на сервер. Из glTF для предпросмотра исключаются внешние ссылки материалов/картинок; текстуры берутся из самого MWF ZIP. При экспорте сохраняется оригинальный набор ресурсов, а новые анимационные данные размещаются в дополнительном встроенном FLOAT-буфере без изменения разделяемых исходных accessor.

Модели/текстуры/звуки из пользовательского «Убойника» сохраняют исходное авторство; новая лицензия на них не назначается. Three.js 0.170.0 и fflate 0.8.2 — MIT, тексты лицензий включены. `SOURCE_MANIFEST.json` внутри экспортированного пака описывает исходники: его хеши нельзя считать хешами отредактированной модели.
