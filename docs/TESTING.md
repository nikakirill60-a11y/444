# Проверка перед использованием

## Что проверяется автоматически

`python3 -m unittest discover -s tests -v` — 9 проверок каталога и ресурсов. Они не запускают Java и не подтверждают работу игровых механик.

`./gradlew --no-daemon build` — компиляция Java и reobfuscation под Forge. Workflow загружает JAR только после успешного завершения этой команды. Не используйте исходный ZIP как мод.

## Ручной smoke test (нужен реальный Minecraft)

Пункты ниже — план, **не отчёт о выполненной игровой проверке**.

1. Запустить чистый Forge 1.12.2-14.23.5.2860 с Java 8 и только новым JAR. Убедиться, что нет Missing Model/Texture и ошибок регистрации.
2. Включить русский язык. В творческом инвентаре проверить ровно три вкладки мода: «Оружие» (16), «Броня» (36), «Вещи» (19). На английском должны отображаться Weapons, Armor, Things.
3. Выдать АК-74 и 64 патрона 5.45; в выживании проверить пустой начальный магазин. Нажать R: по окончании 78 тиков должно остаться 34 патрона в инвентаре, а в магазине — 30.
4. Стрелять по мобу и по стене: попадание наносит урон, через стену урон не проходит. ПКМ у автомата повторяет огонь, количество патронов уменьшается, оружие изнашивается, слышны звуки.
5. Проверить все 16 стволов и 6 видов патронов, включая дробь Дуплета, Сайги и Убойника; неподходящие патроны не загружаются.
6. Частично опустошить магазин, перезарядить: расходуется только недостающее количество. При нехватке патронов магазин заполняется частично. Смена слота во время перезарядки отменяет её без расхода боеприпасов. Повторное R не сокращает таймер.
7. Броня надевается в корректные слоты головы/груди и уменьшает входящий урон. Нельзя ожидать старые объёмные модели — это известное ограничение этапа.
8. Проверить ПНВ: ночное зрение включается при ношении и исчезает не позднее чем через 15 секунд после снятия.
9. Получить урон и применить аптечку: +8 здоровья, ровно 5 успешных применений. При полном здоровье аптечка не расходуется.
10. Повреждённое оружие во вторую руку, ремкомплект в основную: ПКМ ремонтирует, комплект расходуется. Для брони — свой комплект. При отсутствии подходящего повреждённого предмета комплект сохраняется.
11. Сохранить мир с частично заполненным магазином и использованной аптечкой, выйти и зайти: состояние должно сохраниться.
12. В творческом режиме оружие работает без патронов, инструменты не расходуются.
13. Запустить **выделенный Forge-сервер** с тем же модом: убедиться, что нет ошибок загрузки клиентских классов. Подключить два клиента, повторить тесты стрельбы/перезарядки/сохранения. Проверить запрет PvP и команды союзников.
14. Попытка стрелять/перезаряжать в режиме наблюдателя не должна изменять мир или инвентарь.

## Известные отличия этапа

Нет старых 3D-моделей, баллистических сущностей, отдачи, установки модулей, защиты от радиации, специального инвентаря, мобов, декора и рецептов. Предметы без перенесённой функции отмечены подсказкой. Числовые параметры пака импортированы, но итоговый баланс отличается из-за системы брони и урона Minecraft 1.12.2.
