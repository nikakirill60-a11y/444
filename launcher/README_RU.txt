MinETRO Launcher — Windows 10/11 x64
==================================
Распаковать весь ZIP и открыть MinETRO-Launcher.exe.
Сохранить рядом папку Assets, third-party и accounts.public.json. .NET встроен.

Сначала открывается регистрация MinETRO. Для существующего аккаунта есть «Вход».
Подтвердить почту ссылкой из письма, вернуться в лаунчер и войти по паролю.
Если письмо содержит цифровой код, его можно ввести в форме подтверждения.
Основной лаунчер, настройки, установка и папка сборок недоступны до входа.
После выхода доступ снова закрывается. Пароли и токены не сохраняются на диск.

Supabase MinETRO подключён. Правила БД/Storage ограничивают данные своим профилем.
Для массовой регистрации нужно настроить собственный SMTP в Supabase Auth:
встроенная почта Supabase ограничена и не является готовой публичной рассылкой.
Для восстановления кодом в шаблон Reset password нужно добавить {{ .Token }}.
Доставка писем и реальный пользовательский вход пока не проверены.

Выбрать «MinETRO dev» или «MinETRO» в левой панели.
MinETRO пока недоступно. Для MinETRO dev нажать «Запросить доступ».
Заявка появится у администратора в личном кабинете сайта с кнопками
«Подтвердить» / «Отклонить». После решения нажать «Обновить статус».
Одобрение проверяется сервером, а не локальным файлом лаунчера.
Архив MinETRO.zip найден на Drive, но ещё не проверен и не перенесён
в защищённое хранилище: даже одобренному аккаунту загрузка пока недоступна.
Лаунчер не скачивает последние публичные GitHub-релизы автоматически.
Это отдельная тестовая версия 0.6, не автоматическое обновление.

Новая схема обновлений — по файлам: первый раз вся сборка, дальше только
изменившиеся файлы/блоки с SHA256. Новые версии активирует только владелец.
Миры, packv4, скриншоты и личные настройки сохраняются. Config задаётся только
при отсутствии локального файла; обычные обновления его не перезаписывают.
Файловая схема создаёт отдельный экземпляр MinETRO-dev-files и обновляет его
через подготовленную копию с резервной старой версией. ZIP-экземпляры не трогает.
Перед установкой закрыть Minecraft/Prism. Нужно место для копии, rollback и кеша.
Папки .files-backup-* не удаляются автоматически. Подробности — publisher/PUBLISHER_RU.md.
В publisher — инструмент владельца: подготовка и загрузка только изменений,
без автоматической активации. Нужен Python 3.12+. Секретных ключей в ZIP нет.
Настоящая исходная dev-сборка пока не инспектирована и не опубликована.

Кнопки регистрации через Prism нет. Prism остаётся внутренним официальным движком
Minecraft; лицензия Minecraft Java и Java 8 x64 настраиваются в его окне при первом
запуске. Аккаунт MinETRO не заменяет Microsoft. Скин сейчас только в профиле,
отображение в игре и другим игрокам ещё не подключено.

EXE пока не подписан. Не отключать защиту Windows; сверять SHA256 ZIP.
PUBLIC.png — недоступный публичный канал. PREVIEW.png — реальный экран регистрации Windows. HOME/SETTINGS/PROFILE/SKIN.png
сняты с того же приложения с локальным тестовым аккаунтом-транспортом в CI:
это проверка UI, не доказательство реального входа или запуска Minecraft.

Prism Launcher — независимый open-source проект, скачивается из официального
GitHub с проверкой SHA256. Лицензии и уведомления находятся в third-party.
