MinETRO Launcher TEST 0.3 — Windows 10/11 x64
===========================================
Это тестовая оболочка установки/запуска, НЕ готовая полная сборка Minecraft.
Архив полной сборки пока НЕ подключён: кнопки установки/игры отключены честно.
Один MinETRO.jar не заменяет MWF, packv4 и остальные данные сборки.

1. Распакуйте весь ZIP лаунчера в отдельную папку. Запустите MinETRO-Launcher-Test.exe.
   .NET устанавливать не нужно: среда исполнения входит в EXE. Администратор не нужен.
2. Выберите отдельную папку данных. НЕ выбирайте свою рабочую .minecraft.
3. «Подготовить Prism / войти в Microsoft» скачает официальный portable Prism
   11.1.1 с проверкой SHA256. Кнопка входа находится внизу левой панели. Вход выполняется только в Prism/Microsoft.
   Пароли Microsoft и токены Prism эта оболочка не запрашивает и не читает.
   Не вводите пароль Microsoft в форму отдельного профиля MinETRO.
4. Кнопка «Подключить сборку» открывает вкладку «Настройки».
   Когда будет опубликован JSON-канал полной сборки, подключите его HTTPS-ссылкой
   либо через «JSON…» -> «Подключить». Используйте только доверенный источник:
   моды — исполняемый Java-код; SHA256 гарантирует целостность, не безвредность.
   Подтверждённый канал сохраняется локально и доступен после перезапуска EXE;
   самопроизвольного скачивания изменённого манифеста при старте нет.
5. «Установить / проверить» скачает ZIP, проверит SHA256/размер, распакует в новый
   экземпляр Prism и проверит JAR модов. Незавершённая установка не становится готовой.
6. «Играть» передаст запуск в Prism. При первом использовании настройте там
   Microsoft-аккаунт с лицензией Minecraft Java и Java 8 x64 (для Forge 1.12.2).
   Minecraft, библиотеки и Forge загружает Prism; прогресс/ошибки видны в его окне.
   Если автоматический старт прервался на настройке Prism, завершите её и нажмите
   «Играть» ещё раз. При необходимости Windows может попросить VC++ Runtime
   для официального MSVC-варианта Prism — берите его только у Microsoft.

Каждая версия архива ставится отдельно. Обновления не стирают старые миры,
руки packv4, моды и настройки. Миры НЕ переносятся между версиями автоматически:
перед переносом сделайте резервную копию; старая версия остаётся доступна в Prism.
Поле ОЗУ относится к новой установке; память уже установленного экземпляра
настраивается в Prism, чтобы не затирать его пользовательские настройки.
Проверка установленной сборки проверяет JAR из манифеста, не перезаписывает
пользовательские настройки/руки. При повреждении модов используйте новую папку
или восстановите нужный файл вручную после резервного копирования.
Расположение: <папка данных>\prism-data\instances\MinETRO-...\.minecraft\saves

Кнопка отмены останавливает загрузку/распаковку, готовые экземпляры не удаляются.
Закрытие во время установки сначала запрашивает отмену; закройте повторно после неё.
Лаунчер не модифицирует системную Java, реестр, официальный Minecraft Launcher
или посторонние .minecraft. Самообновления EXE и обхода Microsoft-авторизации нет.

Прототип не имеет сертификата подписи кода: Windows SmartScreen может показать
предупреждение. Проверяйте SHA256 опубликованного ZIP; защиту Windows не отключайте.
Windows GUI/installer smoke и сервисные тесты — не проверка запуска полного
модпака: без его архива end-to-end запуск Minecraft не выполнялся.

Скачивается отдельно из официального GitHub, не встроен/не переименован в наш EXE.
