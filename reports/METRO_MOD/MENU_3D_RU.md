## Следующий шаг на ПК: только материалы и текстуры сцены

Сформирован автономный `downloads/finishmenu.py` по **реальным ссылкам mtllib**
из проверенных 35 моделей. Требуется Python 3, без pip/Java/других программ.

1. Положить скрипт в исходную папку `content`, где лежат
   `Metro2033Models.jar` и `Metro2033Textures*.jar`.
2. Открыть `cmd` из адресной строки этой папки и выполнить:

```bat
py -3 finishmenu.py "."
```

3. Из новой папки `metro_menu_finish_parts` загрузить все
   `metro_menu_finish_*.zip` и `menu_finish_inventory.json` на тот же Drive.

Сборщик проверяет Models.jar по ожидаемому SHA256, читает 35 исходных `.m2033gl4`,
находит их diffuse-текстуры и доступные normal/specular/emission-каналы.
По умолчанию выбирает максимальное доступное разрешение не выше 512, либо
минимальное выше, если меньших нет. `--size 1024` и другие поддерживаемые
значения позволяют выбрать другой уровень; окончательное разрешение/шейдерное
совпадение с донором ещё не проверены. Сохраняются исходные байты, не перекодировка.
ZIP независимы, каждый не больше 90 MiB. Все пропуски/ошибки записываются в JSON.

Исходные архивы не изменяются. Клиент, Java и сетевые команды не запускаются,
данные аккаунтов не читаются. Никаких дверных add-on-моделей из декора или оружия
в этот сборщик не добавлено. Существующая выходная папка не перезаписывается.
Сборщик материалов проверен на синтетических архивах; на реальных больших
архивах пользователя он здесь не запускался. ZIP — исходники, не игровой мод.
