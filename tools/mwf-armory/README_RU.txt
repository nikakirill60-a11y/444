MWF ARMORY STUDIO v1.0 — Minecraft 1.12.2 / выбранная закрытая сборка MWF fix1

ЗАПУСК
1. Распакуй ZIP в отдельную папку.
2. Открой MWF_Armory_Studio.html в современном Chrome, Edge или Firefox.
3. Интернет, Node, Java и сервер для работы редактора не нужны. Нужен WebGL2.
Это редактор контент-паков, не Forge-мод и не программа запуска Minecraft.
Встроен актуальный объединённый пак Убойника/Дуплета. Дополнительный bridge-мод НЕ нужен.

БЫСТРОЕ СОЗДАНИЕ ОРУЖИЯ
Арсенал → выбери шаблон → введи уникальный ID (my_railgun) и название → Создать копию.
OBJ / модель → выбери ОДНОВРЕМЕННО OBJ + MTL + все PNG → проверь назначение PNG каждому материалу.
Укажи ось ствола и длину, нажми «Применить импорт». Ось ствола преобразуется в +X.
Стартовая длина 0.64 локальных единиц — это только начало настройки, размеры разных OBJ отличаются.
Центрирование убирает исходное смещение; без него сохраняется положение исходного нуля (с учётом нормализации размера).
После импорта настрой «Модель отдельно от рук», хват обеих рук и положение всего оружия справа.
Проверь обычный вид, ADS, тонкие руки, осмотр 3D, анимации шаблона.
Параметры → название, класс, урон, дробины, дальность, патрон, ёмкость, темп,
перезарядка в секундах, режимы стрельбы, отдача и скорость движения.

МОДИФИКАЦИИ
Обвесы → Создать обвес из OBJ → ID/имя/слот → выбери OBJ + PNG (+MTL).
После импорта обвес разрешён для выбранной пушки. Настрой его положение, угол, размер.
«Показать в 3D» и галочки справа — только предпросмотр.
«Установлен по умолчанию» — реальная настройка пака; один обвес на слот.
Можно разрешить готовый обвес из встроенного пака для другой пушки.
Доступны: barrel (ствол/глушитель), sight (геометрия прицела/ADS/zoom), grip, stock, laser.
Множители отдачи, точности, скорости ADS, флаги глушителя/вспышки используют поля выбранного MWF.
Параметры предмета-обвеса общие для всех пушек с этим ID; его трансформация задаётся для каждой отдельно.
Удаление совместимости не удаляет ресурс из пака: другие пушки могут использовать этот ID.
Два дополнительных ствола Дуплета — декор. Этот редактор не добавляет работающие стволы/новую Java-логику.

НЕСКОЛЬКО PNG
Это одновременные материалы на одной модели, а НЕ выбор разных скинов.
PNG назначаются по map_Kd из MTL/именам, затем объединяются в единый нативный атлас.
Проверь назначения вручную. map_Kd с опциями/нестандартным синтаксисом может потребовать ручного выбора.
Несколько разных PNG: UV строго 0..1; повторяющиеся UV сначала запеки в Blender.
При одном PNG повторяющиеся UV сохраняются, сам PNG не перекодируется.
До 8 PNG, каждый до 4096x4096; итоговый атлас не больше 4096x4096 с защитными краями.
Если атлас велик — уменьши исходные PNG, редактор не уменьшает качество автоматически.
OBJ: до 20 МБ/180 000 треугольников. Поддерживаются UV, нормали, отрицательные индексы,
треугольники, плоские выпуклые/вогнутые многоугольники. Самопересечения/неплоские n-gon лучше заранее триангулировать.
PBR, opacity из MTL, bump/normal, отдельные emissive-карты не импортируются. PNG-прозрачность базовая.

ПАТРОНЫ НА МОДЕЛИ
Для визуального «−1 патрон после выстрела» нужны ОТДЕЛЬНЫЕ OBJ-группы:
bulletModel_0, bulletModel_1, ..., bulletModel_N. Нумерация с нуля.
Корпус должен оставаться отдельной обычной группой. flashModel — необязательная группа вспышки.
Все остальные группы объединяются в gunModel. Дверцы/барабаны/затворы не получают новые анимации автоматически.
Кнопка «Выстрелить» уменьшает число патронов в предпросмотре; звук/отдача/баллистика игры здесь не симулируются.
Если патроны слиты с корпусом, редактор не может надёжно разделить их автоматически.
Перезарядка в этой версии — внутренний боезапас с поштучным заряжанием по Enhanced-шаблону.
Отъёмные магазины и создание произвольных новых ключей/костей не входят в v1.

РЕСУРСЫ
Можно заменить текстуру пушки, загрузить иконку PNG или снять её в режиме «Осмотреть 3D».
Импорт OGG привязывает файл к выбранному событию; используй mono OGG Vorbis для Minecraft.
Прослушивание — отдельной кнопкой. Автоматического преобразования MP3/WAV и микшера нет.
Для каждого события можно назначить свой файл, включая фазы перезарядки и глушитель.
В «Ресурсы → Патроны» можно создать независимую копию патрона, назначить его пушке,
настроить имя, множители урона/точности, стак и режим slug. Иконка/геометрия гильзы наследуются.
Произвольные снаряды, взрывы, эффекты и системы отъёмных магазинов этим не создаются.
Свой скин рук справа используется только в предпросмотре; в игре используется скин игрока.

СОХРАНЕНИЕ
«Сохранить проект» — один .armory-project.json со всем паком, ресурсами и текущими несведёнными смещениями.
«Открыть проект» восстанавливает проект. Можно дополнительно сохранить в IndexedDB этого браузера.
Для переноса на другой ПК и резервных копий используй ФАЙЛ проекта, а не только браузер.
Переключение оружия сохраняет его изменения в проекте и запекает смещения. Не нужно экспортировать каждую пушку отдельно.
Undo/Redo отменяет параметры/позы/совместимость. Создание, импорт ресурсов, переключение оружия — границы истории.
Импорт не заменяет исходный ZIP на диске. Закрытие вкладки без проекта/экспорта теряет текущую работу.
Экспорт ZIP — весь текущий пак, а не только выбранная пушка, со всеми созданными предметами.
Размер импортируемого/экспортируемого ZIP до 64 МБ, распакованного пака до 160 МБ, не более 10 000 файлов.
Проекты до 95 МБ. Это редактор отдельного пака, не всей огромной библиотеки MWF.

УСТАНОВКА В ИГРУ
Полностью закрой Minecraft. Убери старые ZIP/папки с теми же ID.
Положи новый экспортированный ZIP ЦЕЛИКОМ в ModularWarfare/ своего клиента.
На сервере должен быть тот же пак. Основной MWF JAR не заменять.
Если ранее использовал старый 4-патронный Дуплет: сначала разряди его и удали только
metro-duplet-bridge*.jar из mods клиента/сервера. Основной ModularWarfare оставь.
Встроенный Дуплет имеет 2 патрона. Смена ёмкости не мигрирует уже сохранённый старый NBT.

ГРАНИЦЫ ТОЧНОСТИ
Предпросмотр — Three.js, НЕ работающий Minecraft. Матрица держания/руки/геометрия берутся из пака,
но освещение, PIP/сетка прицела, полноценная отдача, эффекты ЛЦУ, покачивание/OptiFine/коллизии не воспроизведены.
Готовые исходные паки должны использовать текстовый embedded-buffer Enhanced glTF со стандартными отдельными узлами рук.
Готовые BASIC-пушки, GLB, внешние glTF-буферы, skeletal skin/joints не открываются.
НОВЫЕ OBJ импортируются в рабочий Enhanced-шаблон, а не открываются как готовые BASIC-пушки.
Импорт не создаёт новую анатомическую анимацию: использует руки/действия шаблона.
Нативный запуск Minecraft/Forge не автоматизирован; экспорт необходимо проверить в своей игре.
Программа не устраняет OpenGL 1281 и не добавляет функции, которых нет в выбранном MWF.
Ресурсы сторонних авторов сохраняют лицензии/авторство; собственные модели используй с разрешения правообладателей.
