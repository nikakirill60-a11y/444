01 / РУКИ

Настрой хват

Положение и углы меняются сразу. Настройки применяются к обычным и тонким рукам.

X — вдоль оружия · Y — высота · Z — вбок. Это смещения относительно исходной позы, не абсолютные координаты.

Как перенести в игру
  1. Настрой обе руки и проверь ADS.
  2. Нажми «Экспорт пака ZIP».
  3. Замени старый пак в ModularWarfare и перезапусти Minecraft.
АРСЕНАЛ / ПРОЕКТ

Создай своё оружие

Встроены Убойник и Дуплет. Новый предмет копирует проверенный Enhanced-шаблон, после чего ты заменяешь модель и параметры.

ID: латиница, цифры, _. Переключение сохраняет правки в текущем проекте. Сам исходный ZIP не меняется.

Для надёжной копии используй «Сохранить проект» вверху. Локальное хранилище зависит от браузера и пути HTML.

БАЛАНС / СТРЕЛЬБА

Параметры оружия

Урон задан за одну пулю/дробину. Ёмкость — внутренний боезапас; магазинные системы и новые механики Java не создаются конфигом.

ГЕОМЕТРИЯ / МАТЕРИАЛЫ

Импорт OBJ + PNG

Материалы MTL связываются с PNG автоматически. Назначение можно изменить ниже.

Все PNG используются одновременно через атлас, а не как сменные скины. Для нескольких PNG UV должны быть 0..1. Максимум: 180 тыс. треугольников, 8 PNG, атлас 4096². Группы bulletModel_0, bulletModel_1… скрываются по числу патронов. Остальные детали объединяются в корпус; шарниры не создаются.

Модель отдельно от рук
ОБВЕСЫ / СОВМЕСТИМОСТЬ

Модификации

Параметры обвеса общие для всех пушек, использующих этот ID. Положение и установленный по умолчанию обвес — отдельные для текущего оружия. «+2 ствола» остаётся декором, без дополнительного мода.

ТЕКСТУРЫ / ЗВУКИ

Ресурсы

Для снимка включи «Осмотреть 3D» и выбери ракурс. Руки и фон будут убраны на время снимка.

Для позиционного звука Minecraft нужен mono OGG Vorbis. Конвертер из MP3/WAV не встроен.
