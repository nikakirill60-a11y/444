MWF POSE STUDIO v3 — ДУПЛЕТ: +2 СТВОЛА ТОЛЬКО ДЕКОР

Встроен общий пак Дуплет v2 + Убойник v5. Дополнительный мод НЕ нужен.
У обоих вариантов Дуплета вместимость 2, полная зарядка номинально 3 секунды.
+2 ствола только отображаются на модели и не дают дополнительных выстрелов.
Старый ID metro_duplet_4 оставлен ради сохранения предметов, а не ёмкости 4.
Выбрать оружие можно в правой панели «Выбор оружия / другой пак».
Флажки обвесов — только предпросмотр. В игре установка штатная, через MWF.
Экспорт сохраняет текущий косметический пак, без JAR и без переходника.

ПЕРЕД ОБНОВЛЕНИЕМ старой сборки сначала разрядить Дуплеты, затем закрыть игру,
удалить metro-duplet-bridge-1.0.0.jar из mods клиента/сервера, заменить старый
общий ZIP на новый. Убойник уже внутри; дубликаты паков не оставлять.
Старые редакторы v2 с рабочей ёмкостью 4 для новых экспортов не использовать.
Оба Дуплета используют один glTF: правки рук распространятся на оба.
Положение всего оружия сохраняется в конфиге выбранного варианта.

Геометрия и текстуры прежние. Полноценная переломка не восстановлена,
отдельных исходных патронов нет; Minecraft этим редактором не запускается.
Ниже — общая инструкция по управлению редактором.

MWF POSE STUDIO v1 — редактор рук «Убойника» / Enhanced
====================================================

ЗАПУСК НА WINDOWS
1. Распакуйте ZIP программы в любую папку (не в Minecraft/mods).
2. Откройте MWF_Pose_Editor.html двойным щелчком в современном Chrome/Edge/Firefox.
3. Интернет, Node.js, Python и установка EXE не нужны.
   Требуется браузер с WebGL2 и включённым аппаратным ускорением.
   В редактор встроен исходный «Убойник v5» — модель появится автоматически.

ЭТО НЕ ЗАПУЩЕННЫЙ MINECRAFT
Программа воспроизводит геометрию, текстуры, анимационные ключи и основную
матрицу первого лица MWF-Shining 2024.2.4.6f-fix1. Это не гарантия полного
совпадения с игрой. Освещение, OptiFine/шейдеры, броня на руках, динамический
sway/отдача, столкновения, физика и поведение сервера здесь не воспроизводятся.
Для совпадения кадра выставьте FOV и формат экрана как в игре. Режим осмотра
3D — свободная камера, НЕ точная поза игрока от третьего лица.

КАК ПРАВИТЬ
- Выберите левую или правую руку.
- «Обычный хват + ADS» — изменения используются в обычном держании,
  прицеливании, стрельбе, осмотре и других действиях вне зарядки.
- «Руки при перезарядке» — отдельные смещения для зарядки/выгрузки патронов.
  Между ними редактор интерполирует изменения на подготовительных/завершающих фазах.
- X/Y/Z и углы меняются ползунками или числами, результат виден сразу.
  Это добавочные смещения в координатах модели, не абсолютные мировые координаты.
- Масштаб руки общий для всех её поз. Повороты XYZ локальные относительно
  исходного поворота узла. Меняются и обычный, и тонкий варианты рук.
- Включите ADS и проверьте положение пальцев. Можно включить свободный 3D-осмотр.
- Перезарядку можно проиграть, остановить и промотать ползунком времени.
- Настройки оружия отдельно меняют его положение вместе с руками.
  «Сохранять конечную позу ADS» компенсирует изменение обычной позы.
- Свой PNG-скин 64×64 используется только в предпросмотре: в игре скин игрока.
  При открытии проекта выберите свой скин заново.
- Обвес включается только для осмотра. Это не установка обвеса на предмет
  и не автоматическая смена хвата по цевью.

СОХРАНЕНИЕ
«Сохранить проект» → .pose-project.json: включает исходный ZIP и настройки рук.
Откройте его кнопкой «Открыть проект», чтобы продолжить работу. Это не файл для игры.
Без сохранения/экспорта изменения останутся только в памяти открытой вкладки.

«Экспорт пака ZIP» → готовый контент-пак. Изменения рук записываются в glTF:
статические TRS узлов и анимационные ключи; положение оружия — в render JSON.
Это не просто неработающий JSON с новыми полями.

УСТАНОВКА В ИГРУ
1. Полностью закройте Minecraft.
2. Уберите прежний ZIP и распакованные копии пака с теми же предметами.
   Сохраните резервную копию отдельно от ModularWarfare.
3. Положите экспортированный *_POSE_EDIT.zip ЦЕЛИКОМ в .minecraft/ModularWarfare/.
4. Запустите Minecraft и проверьте результат. Для сервера нужен тот же ZIP.
5. Не кладите HTML редактора или проект в mods/resourcepacks/ModularWarfare.

ОГРАНИЧЕНИЯ v1
Другие ZIP можно открыть, если это Enhanced с текстовым glTF, встроенными
буферами и отдельными стандартными узлами рук, как у данного «Убойника».
BASIC/OBJ, GLB, скелетные skin/joints и кубические анимационные кривые рук
не поддерживаются. Переключение хвата по модификациям не реализовано.
Изменения новых поз по обвесу требуют дополнительной игровой логики.
При импорте собственного пака сохраняются остальные ресурсы и конфигурации.
Редактор не исправляет ошибку OpenGL 1281. Для её разбора нужен игровой лог.

ПРИВАТНОСТЬ И АВТОРСТВО
Все файлы обрабатываются в браузере; запросов к серверу программа не делает.
Модели/текстуры/звуки предоставлены пользователем из «Убойника»;
редактор не меняет их авторство и не устанавливает новую лицензию на них.
MWF JAR не включён. Three.js и fflate — MIT, тексты лицензий рядом.
