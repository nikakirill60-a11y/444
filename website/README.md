# MinETRO beta website

Статический русский сайт без сборщика; account.html обращается напрямую к Supabase Auth и owner-only профилю.
Запуск: `python -m http.server 3000 --bind 0.0.0.0 --directory website` из корня репозитория.

Vercel: проект `minetro-beta`, Root Directory `website`, Framework `Other`, Output Directory `.`.
Конфигурация заголовков безопасности находится в `vercel.json`. Автоматические Git-деплои
при создании проекта были выключены; публикация выполняется отдельно через Vercel.

- В `index.html` оставлена только загрузка Windows-лаунчера. Отдельный JAR на сайте больше не предлагается.
- Не публикуйте ссылку на ещё не выпущенный релиз. JAR — не полная сборка.
- Блок «Перед поездкой» и копирование локального адреса удалены.
- `assets/tunnel.jpg` — атмосферный AI-концепт, не игровой скриншот.
- `assets/mark.svg` — существующая иконка MinETRO из Windows-лаунчера.
- Регистрация/вход: `/account.html`, тот же проект и public key, что у лаунчера. Скин пока меняется в лаунчере.
- Проверки: `python -m unittest discover -s tests -p test_beta_website.py`.

Локальный шрифт Oswald (Cyrillic + Latin) поставляется через
`@fontsource-variable/oswald`; лицензия SIL OFL 1.1 — `assets/Oswald-LICENSE.txt`.
Внешние шрифтовые сервисы и аналитика не подключены.

Браузерный smoke-test: установите Playwright во временную папку, затем
запустите `node tools/test_beta_website_browser.cjs` из корня (NODE_PATH должен
указывать на установленный node_modules). Можно передать CHROMIUM_EXECUTABLE_PATH
для своего Chromium и SITE_URL для адреса тестового сайта. Проверяются ширины
320/390/768/1440, отсутствие горизонтальной прокрутки/ошибок ресурсов, FAQ,
мобильное меню/Escape, три шага начала игры и единственная загрузка лаунчера.
Эта проверка не подтверждает совместимость сайта со всеми браузерами.


## Аккаунты

Email + пароль + ник (3–16 ASCII букв/цифр/подчёркиваний); пароль 12–128 символов.
Подтверждение email обязательно. После ссылки нужен явный вход с паролем;
страница удаляет параметры URL и не принимает присланный в URL bearer token.
Сессия только в памяти вкладки: без localStorage/cookie/refresh token, очищается
при выходе, pagehide и истечении. Профиль читается только по auth.uid, RLS остаётся включён.
Публичный publishable key не является секретом; service-role ключей на сайте нет.
Пароли передаются только HTTPS непосредственно Supabase, не Vercel/GitHub.
CSP блокирует нативную отправку формы; без JavaScript регистрация недоступна.

В Supabase разрешён точный redirect `https://minetro-beta.vercel.app/account.html`.
Старый site_url функции `account-confirmed` оставлен для лаунчера.
Собственный SMTP не подключён: встроенная отправка имеет строгие ограничения
и может не отправлять письма внешним адресатам. Для публичной регистрации нужен
SMTP и проверка реальной доставки; mock-тесты ниже этого не подтверждают.
Тестовые аккаунты в production автоматически не создаются.

- `node --test tests/website_accounts.test.mjs` — API/валидация/безопасность (mock).
- `node tools/test_website_accounts_browser.cjs` — UI 320/390/768/1440 (mock Auth),
  предварительно запустить сайт на порту 3000. Требуется Playwright, как выше.

## Вики

`/wiki.html` — четыре вкладки: Оружие, Броня, Мутанты, Предметы.
Ссылка «Вики» добавлена в основное меню. На планшетах меню сворачивается до
1050 px, чтобы ссылки не перекрывали логотип и кнопку загрузки.

Каталог содержит **260 карточек** по активным регистрациям MetroPort dev.33
и опубликованному арсеналу MWF v10 / metro6:
- Оружие: 28 (25 стволов MWF, мачете и 2 гранаты).
- Броня: 110 (36 исходных, 58 MCMOD, 15 BlackRazid, 1 маска Exodus).
- Мутанты: 18 (12 BlackRazid, 4 MetroCraft, 2 Exodus).
- Предметы: 104 (патроны/магазины/обвесы MWF, выживание, медицина,
  рюкзаки, нашивки, валюта и материалы, еда и вода).

По уточнению пользователя вики не включает блоки, двери/гермоворота,
светильники/рычаги, служебные блоки, спавнеры и декоративные модели окружения.
Они исключены только из сайта, не из игровой сборки.

У каждой карточки есть описание, доступные базовые параметры, ID и ссылка
на исходник. Боеприпасы, магазины, обвесы и оружие связаны ссылками.
241 исходная иконка взята из ресурсов сборки; если инвентарной иконки нет,
стоит явная пометка «Без иллюстрации», не чужой скриншот и не UV-атлас.
Поиск по названию/ID и подкатегория работают в выбранном разделе; «ё» и «е»
считаются одинаковыми. JavaScript показывает по 24 карточки с кнопкой «Показать ещё».
Прямая ссылка `#entry-modularwarfare-metro_velopal` открывает нужный раздел
и карточку, даже если её ещё не было в первых 24 результатах.

**Не возвращены** исключённые собственные стволы/боеприпасы MetroPort,
золотая/алмазная маски, тестовая кирка, отключённые мебель/тоннели/рельсы.
Нет выдуманных рецептов, лута, мест обитания или окончательного серверного баланса.
Урон оружия указан на один снаряд, для дроби отдельно дано число дробин.
Защита брони — коэффициент предмета из конфигурации, не устаревший sourceProtect
целого комплекта. Крыса BlackRazid не атакует; контакт головы демона — 10 урона.
Медведь и Велопал — дробовики на 6 зарядов. Дуплет — 2 / 4 с модулем и companion JAR.

Данные и HTML генерируются без сторонних Python-библиотек:
`python tools/build_website_wiki.py --pack /path/to/Metro_Full_Arsenal_MWF_fix1_v10_icons.zip`.
ZIP проверяется по SHA-256. Генератор читает JSON/регистрации из репозитория,
обновляет `wiki-data.json`, `wiki-manifest.json`, статические карточки в `wiki.html`
и `assets/wiki/`. Участок CATALOG BEGIN/END не править вручную.
Ссылки на источники закреплены за коммитом `f9ce878` (исходники данных).
Повторная генерация даёт байт-в-байт одинаковый результат.
Без JavaScript доступны все четыре раздела по якорям. С JavaScript работают
ARIA-вкладки, стрелки влево/вправо, Home/End, Space, история назад/вперёд
и прямые ссылки `#weapons`, `#armor`, `#mutants`, `#items`.
Данные авторизации, загрузки и CSP не изменялись.

Проверки:
- `python -m unittest discover -s tests -p test_website_wiki.py` — структура/ссылки/ресурсы.
- `node tools/test_website_wiki_browser.mjs` — Chromium, ширины 320/390/768/1024/1440,
  переключение, клавиатура, история, якоря, мобильное меню и режим без JavaScript.
  Требуется `playwright-core` (или абсолютный путь к его `index.mjs` в
  `PLAYWRIGHT_MODULE`), `CHROMIUM_EXECUTABLE_PATH` для своего Chromium,
  `SITE_URL` по умолчанию `http://127.0.0.1:3000`. Скриншоты сохраняются
  в игнорируемом `artifacts/website-wiki/`.

- `python -m unittest discover -s tests -p 'test_website_wiki*.py'` — структура,
  полнота активных каталогов, исключения, соответствие параметров и SHA иконок.
- `node tools/test_website_wiki_catalog_browser.mjs` — поиск/фильтры/пагинация,
  параметры Велопала, межкатегорийные ссылки, карточка вне первых 24,
  история/перезагрузка, отсутствие XSS/переполнения, загрузка изображений,
  все 260 карточек без JS. Переменные окружения — как у smoke-test выше.

Проверки UI/конфигураций не являются запуском сборки в Minecraft.
